## 關鍵參數速查

### 電調電流需求

| 馬達組合 | 單顆滿載 | 四軸峰值 | 建議電調 |
|---------|---------|---------|---------|
| VCI 1404.5（3S） | ~15A | ~60A | ≥40A |
| VCI 1408（4S） | ~20A | ~80A | ≥40A |
| DYH1408 / 1507（4S） | ~25A | ~100A | **≥45A** |

### BEC 供電需求

| 負載 | 電流 | 最低BEC |
|------|------|---------|
| 接收機（ELRS） | 0.2–0.5A | 5V/1A |
| LED 22顆（40%亮度） | 1.0–1.5A | 5V/2A |
| LED 22顆（50%亮度） | 1.5–2.0A | **5V/2.5A** |
| 總計（安全餘裕） | **2.0–2.5A** | **5V/3A** |

> **F411 為何只能 22 顆 LED？** BEC 5V/2A，LED 1.5A + 接收機 0.5A = 2A 滿載。超過會過熱重啟。

### Target 刷機速查

| 飛控 | Betaflight Target | 主控類型 | 可以互刷？ |
|------|------------------|---------|-----------|
| HAKRC F411 | `HAKRCF411D` | STM32F411 | **✗** |
| RATE F4 | RATE 對應 AT32 target | AT32F435 | **✗** |
| Oxbot Flow AIO45 | `OXBOT_FLOW_AIO45` | AT32F435 | **✗** |
| Flywoo GOKU GN745 | `FLYWOOF745AIOV2` | STM32F745 | **✗** |
| SpeedyBee F405 | `SPEEDYBEE_F405AIO` | STM32F405 | **✗** |

> **⚠️ 絕對不可互刷！刷錯會變磚。**

## 本隊配置建議

### 攻擊機（射手）

```
飛控：Oxbot Flow AIO45（或 RATE F4）
馬達：DYH1408 或 1507（4S）
電池：4S 850–960mAh / 150C
槳：  GF 2828-3
總重：285–295g
設定：雙向DShot ON、RPM濾波、LED亮度45
```

### 硬防（守門）

```
飛控：RATE F4 或 HAKRC F411
馬達：VCI 1408（4S）
電池：4S 750–850mAh / 95C
槳：  GF 2828-3
總重：270–285g
設定：F411關雙向、LED亮度35、電流計210
```

### 輕防（控場）

```
飛控：HAKRC F411（最輕）
馬達：VCI 1404.5（3S）
電池：3S 1100mAh / 100C
槳：  GF 2828-3
總重：250–270g
設定：ANGLE優先、慢Rates、LED亮度35
```

## 避坑指南

| 問題 | 症狀 | 解決 |
|------|------|------|
| **BEC過熱** | LED閃爍、飛控重啟 | F411降LED亮度到30–35 |
| **刷錯target** | 連不上、馬達不轉 | DFU模式重刷正確target |
| **RPM濾波失效** | F411開雙向後不起轉 | F411原廠關閉雙向DShot |
| **孔距不合** | RATE裝不上 | 確認機架25mm還是25.5mm |
| **電流計不準** | OSD顯示異常 | F411設210、其他實飛校正 |
