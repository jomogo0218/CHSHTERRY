## 三、球機比較維度（怎麼讀表）

| 維度 | 為何重要 | 怎樣算好 |
|------|----------|----------|
| 協定 | 對上飛控接收端 | **ELRS 內建** 或確定有 ELRS 模組 |
| 系統 | ARM＝AUX1、Model Match、全隊模型檔 | **EdgeTX** |
| 開關／通道 | ARM、PREARM、ANGLE、TURTLE、切色 | ≥ 足夠實體開關；LiteRadio 僅 8ch 偏緊 |
| 搖桿 | 耐操、手感 | **Hall**（少買電位器入門機當主力） |
| 功率 | 室內夠用即可 | 100–250 mW 通常夠；1 W 是餘裕不是必須 |
| 重量／體型 | 學生長時間握、攜帶 | Pocket／Zorro 輕；Boxer 穩 |
| 電池 | 比賽日續航 | 可換 18650／21700 較方便備援 |
| 價格／台數 | 球隊預算 | 寧可多買 Pocket，少買雙頻旗艦 |

## 四、採購排序（依本資料）

1. **RadioMaster Pocket ELRS** — 批量  
2. **RadioMaster Boxer ELRS** — 射手／教練（1 W、全尺寸搖桿、開關多）  
3. **RadioMaster Zorro ELRS** 或 **Jumper T-Pro ELRS**／**iFlight Commando 8 V2** — 手把  
4. **TX16S MKII ELRS** — 0–1 台母機  
5. 備案：Jumper T20S、TX12 MKII  
6. 劃掉：DJI 全線、TBS 新購、Herelink、純練習極簡機當主力
