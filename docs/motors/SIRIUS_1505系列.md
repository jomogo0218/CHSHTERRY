# SIRIUS 1505 系列無刷馬達規格記錄

> 資料來源：產品介紹圖、工程圖、基本參數表與 4S 負載參數表。
> **F9A-B 使用資料已齊**（外形、重量、孔距 Φ12／槳孔 Φ5，以及 3800／4800／5000KV 的 4S 負載表）。
> **可選補：** 3800KV／5000KV 表底被裁切的第四種槳（不影響主線選型）。
> 基本參數表「最大電流／功率／拉力」可能跨不同槳取欄位最大值，不可直接換算同一工作點力效。
> 本檔僅保留 F9A-B 可使用的 **4S** 型號與測功資料。
