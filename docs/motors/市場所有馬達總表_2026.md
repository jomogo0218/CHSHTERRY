### ⚠️ 常見誤區

#### 1. **安裝孔不相容**

| 孔距標示 | 實際 PCD | 相容性 | 範例型號 |
|----------|----------|--------|----------|
| **9×9mm M2** | ~12.73mm | ✅ 主流 | EMAX ECO / iFlight XING / BrotherHobby TC |
| **Φ9 4-M2** | 9mm | ❌ 獨立系統 | VCI 1404 4500KV / LAN NRC |
| **12×12mm M2** | ~16.97mm | ✅ 可兼容更大機架 | Flywoo NIN V2 / T-HOBBY F1404 |
| **16×16mm M2** | ~22.63mm | ✅ 1408 專用 | T-Motor F1408 / GEPRC GR1408 |

#### 2. **KV 值選擇錯誤**

- **3S 足球機**：建議 **4500–4800KV**（響應快、轉向靈活）
- **4S 足球機**：建議 **3900–4600KV**（拉力足、續航平衡）
- **避免使用 6000KV+**：過高 KV 會導致電流過大、溫度過高、續航短

#### 3. **忽略溫度測試**

| 測試螺旋槳 | 安全範圍 | 過熱範圍 | 處理方法 |
|-----------|---------|---------|---------|
| GF 2828-3 | ≤95°C | >110°C | 降低油門上限或換低 KV |
| GF 3016-3 | ≤85°C | >100°C | 增加通風或換 1408 |
| HQ T3×3×3 | ≤80°C | >95°C | 避免持續滿油門 |

## 🔧 技術名詞解釋

| 名詞 | 說明 |
|------|------|
| **9N12P** | 9 槽 12 極（定子繞組與磁鐵配置） |
| **12N14P** | 12 槽 14 極（更高轉速、更平滑） |
| **N52H / N52SH** | 磁鐵材質等級（H=高溫、SH=超高溫） |
| **NSK / NMB** | 日本品牌軸承（耐用、低阻力） |
| **相間內阻** | 電機線圈電阻（越低越高效） |
| **空載電流** | 馬達不帶槳時的電流（越低越省電） |
| **T-mount** | Φ1.5mm 快拆槳座（免螺絲鎖緊） |
| **力效（g/W）** | 每瓦功率產生的拉力（越高越省電） |

## 📈 2026 市場趨勢

### ✅ 主流方向

1. **輕量化競賽**：1404 馬達主導 200mm 足球機市場
2. **T-mount 普及**：Φ1.5mm 快拆槳座成為新標準
3. **多 KV 選擇**：同一款馬達提供 3–5 種 KV 版本
4. **溫控設計**：散熱結構、磁鐵間隙優化成為賣點

### 📉 淘汰趨勢

1. **過重型號**：12g 以上的 1404 馬達逐漸退出市場
2. **單軸徑版本**：只提供 5mm 軸的型號被 1.5mm T-mount 取代
3. **無測功數據**：缺乏官方測試數據的品牌競爭力下降
