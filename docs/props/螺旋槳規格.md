# 螺旋槳規格記錄

## GEMFAN（乾豐）2820-3

> 資料來源：原廠產品說明與規格表。定位為「200mm 無人機足球搭配小電機」，主打減重、靈活、低成本。

| 項目 | 數值 |
|------|------|
| 型號 | 2820-3（2.8 吋，三葉） |
| 材質 | PC |
| 螺距 | 2 英寸 |
| 顏色 | 透明、螢光黃 |
| 槳葉直徑 | 71.12 mm |
| 中心厚度 | 5 mm |
| 中心孔內徑 | T-mount 1.5 mm |
| 最大槳葉寬度 | 12.2 mm |
| 重量 | **1.4 g** |
| 推薦馬達 | **1104–1404** |
| 起飛重量 | **180 g** |

### 適用性

- 軸徑 **1.5 mm（T-mount）** 與本專案所有馬達幾何相容。
- 但官方推薦僅到 **1404**、起飛重量僅 **180g**，明顯低於 F9A-B 常見的 250–300g 機體。
  掛在 **1408／1507** 上會偏「小槳大馬達」：轉速拉很高、推力上不去、力效差。
- 三款槳中**最輕（1.4g）、螺距最低（2.0）**，同轉速拉力最小、電流與溫升最低。
- 合理用途：**輕量控場防禦機**（搭 1404／1404.5）或**練習、降溫測試**用槳，不建議當比賽主力。

## GEMFAN 2826-3（無人機足球專用）

> 資料來源：原廠產品圖與規格表。標示為「1205-4300kv 电机专用」、200mm 足球機應用。

| 項目 | 數值 |
|------|------|
| 型號 | 2826-3（2.8 吋，三葉） |
| 材質 | PC |
| 螺距 | 2.4 英寸 |
| 顏色 | 紅色、藍色（圖面另有青／橙等配色） |
| 槳葉直徑 | 71 mm |
| 中心厚度 | 5.5 mm |
| 中心孔內徑 | 1.5 mm，三孔 |
| 最大槳葉寬度 | 13.3 mm |
| 重量 | 1.47 g |
| 推薦馬達 | 1205–4300KV |
| 推薦起飛重量 | 230 g |

### 產品說明摘要

- 專為 **200mm 無人機足球**設計。
- 搭配 **1205-4300KV** 無刷馬達，強調飛行更靈活、降低足球機組裝成本、適合青少年操作。

### 適用性

- 官方推薦是 **1205 級**，不是先前 VCI 1404／1408／1505 的主推槳。
- 若硬上 1404／1408：螺距 2.4 介於 2820（2.0）與 2828（2.8）之間，負載可能比 2828 輕、比 2820 重，但仍需實測電流與溫度。
- 推薦起飛重量僅 **230g**，屬輕量 200mm 足球機等級。

- 官方起飛重量 **300g**，比 2826 的 230g 更高一檔。
