### ⚠️ 重要選型原則

#### 1. **C 數優先原則**

對於足球機等高電流應用：
- ✅ **850mAh × 150C = 128A** → 完全足夠暴力對抗
- ⚠️ **1100mAh × 75C = 82.5A** → 容量大但 C 數不足會壓降
- ❌ **1300mAh × 60C = 78A** → 持續電流不足，會發熱、壓降嚴重

> **結論**：高 C 小容量 > 低 C 大容量

#### 2. **重量紅線**

| 機型 | 電池預算 | 推薦重量 | 極限重量 |
|------|---------|---------|---------|
| **200mm 足球機** | ~100g | 85–105g | ≤115g |
| **3 吋 Toothpick** | ~70g | 53–85g | ≤95g |
| **4 吋長航** | ~120g | 100–140g | ≤160g |

#### 3. **接頭相容性**

| 接頭 | 持續電流 | 適用電池 | 相容性 |

| **XT30** | 額定約 30A（短時峰值可更高，但仍建議粗線＋良好焊接） | 650–1100mAh 3S–4S | ✅ 足球機首選；高 C 瞬間電流≠接頭額定，實務仍普遍使用 |

## 電池使用與保養

### ✅ 充電規範

| 項目 | 標準 LiPo | LiHV 電池 | 注意事項 |
|------|-----------|-----------|----------|
| **標稱電壓** | 3.7V/芯 | 3.8V/芯 | LiHV 可充更高電壓 |
| **充電截止電壓** | **4.20V/芯** | **4.35V/芯** | **FAI 規則限制 4.25V/芯** |
| **儲存電壓** | 3.80–3.85V/芯 | 3.85V/芯 | 長期不用請儲存電壓 |
| **放電截止電壓** | 3.0V/芯 | 3.0V/芯 | 不要過度放電 |
| **充電電流** | 1–2C（推薦 1C） | 1–2C | 快充會減少壽命 |

> **⚠️ FAI F9A-B 規則**：比賽用電池充電不得超過 **4.25V/芯**（4S≤17V）

#### 充電前檢查清單

- ✅ 電池外觀完好（無鼓包、破損）
- ✅ 平衡頭連接正確
- ✅ 充電器設置正確（電壓、電流、C 數）
- ✅ 充電時有人看守
- ✅ 在防火袋／防火箱內充電

### 🔋 使用注意事項

#### 1. **溫度管理**

| 溫度範圍 | 狀態 | 處理方法 |
|----------|------|----------|
| **≤60°C** | ✅ 正常 | 可繼續使用 |
| **60–80°C** | ⚠️ 偏熱 | 休息 10 分鐘再充電 |
| **80–100°C** | 🔥 過熱 | 檢查配置、降低油門上限 |
| **>100°C** | ⚠️ 危險 | 停用、檢查電池狀態 |

#### 2. **壽命管理**

| C 數等級 | 循環壽命 | 實際使用 |
|----------|----------|----------|
| **75–95C** | 300–500 次 | ~3–6 個月 |
| **100–120C** | 200–300 次 | ~2–4 個月 |
| **150C** | 150–250 次 | ~1.5–3 個月 |

> **提示**：競賽用高 C 數電池壽命較短，建議定期輪換

#### 3. **安全警示**

🚨 **立即停用情況**：
- ❌ 電池鼓包（充氣）
- ❌ 外觀破損、漏液
- ❌ 內阻異常升高（充電變慢）
- ❌ 單芯電壓差 >0.1V
- ❌ 飛行後異常發燙（>100°C）

## 🔧 技術名詞解釋

| 名詞 | 說明 |
|------|------|
| **C 數（C-Rate）** | 放電倍率，表示電池可安全放出的電流倍數。100C = 可放出 100 倍容量的電流 |
| **LiPo** | 鋰聚合物電池，標稱電壓 3.7V/芯 |
| **LiHV** | 高壓鋰聚合物電池，標稱電壓 3.8V/芯，可充至 4.35V/芯 |
| **1S / 3S / 4S** | 串聯電芯數量（1 芯 / 3 芯 / 4 芯） |
| **XT30 / XT60** | 電池接頭規格（30A / 60A 額定電流） |
| **JST-XH** | 平衡充電頭（用於均衡各芯電壓） |
| **mAh（毫安時）** | 電池容量單位，1000mAh = 1Ah |
| **Wh（瓦時）** | 能量單位，Wh = V × Ah（例：14.8V × 0.85Ah = 12.58Wh） |
| **內阻（mΩ）** | 電池內部電阻，越低越高效、發熱越少 |
| **循環壽命** | 電池可充放電次數（通常 200–500 次） |
