電池

預算約 100g，一定要高 C。3S／4S 都可用，但用途不同。

本章目錄 3S／4S 電壓表 過放風險 本隊已購 4S 建議 3S 備選

為什麼一定要高 C：1408 級滿載約 20A／顆；1507 滿載 24.6A／顆 → 四軸爆發可到 80–100A。

公式 持續電流 ≈ 容量(Ah) × C：850mAh×95C ≈ 81A 對 1507 偏緊； 850mAh×150C ≈ 128A 才夠。

配 1507 請直接上 V5 150C 或 GNB 120C，不要用 650／750 低容量。

電池過放（學生最常毀電的原因）

過放＝電壓被拉太低還繼續飛。 損害通常不可逆——不是「充飽就好」。檢錄只有 9 顆電，一顆打穿就少一顆；硬撐會讓整隊電池陸續報廢。

為什麼足球機特別容易過放

  • 850mAh 很小：對抗局平均十數安培，理論續航本來就卡在 3 分鐘邊緣。
  • 1507／1408 電流大：猛頂瞬間壓降劇烈，燈號會比「靜止電壓」更早警告。
  • 看不見遙控電壓：只能靠 LED 紅閃——沒開警告＝不知道在過放。
  • 捨不得換電：9 顆電若不輪替，同一顆連打多 set 最容易打穿。

先記住：300g 是上限，不是目標。 送檢重量包含球框、電池、馬達、槳、飛控、電調、LED、線材、螺絲、膠帶與所有固定件。

299g 貼上限 把合法重量幾乎用滿，硬碰硬時較不容易被推開 僅剩 1g 容錯；秤差、膠帶、換線或維修都可能超重；續航與靈活性最差 只適合實秤穩定且明確採硬撞戰術的攻擊機

為什麼學生機常接近 300g？

20／22cm 球框、碳板、護罩、LED、線材和 80–100g 高 C 電池疊加後，本來就容易落在 290g 以上； 這通常是組裝結果，不代表 299g 一定是最佳性能。

不要為了「用滿規則」額外加配重。

推重比：1507 單顆 651g → 四軸約 2.6kg；對 300g 球體推重比約 8–9:1。 動力過剩，瓶頸是散熱、電池 C 數與 300g 總重。
先做這一步：用電子秤實測「框架＋電池＋4馬達＋槳＋飛控」。 靠近 300g 就優先讓防禦減重（改 1404.5），攻擊可保留 1507 或 DYH。

本頁依 Betaflight 官方文件整理。本隊學生機飛控韌體統一 4.5.x（教練發機時會刷好）。不同小版本預設可能略有差異，刷完一定要重新確認；若將來跨大版本（例如升到 2025.12），官方要求 Chip Erase（全清）並重新設定，不要直接把舊的 diff 貼上去。

1
準備工具與飛控

拆槳、裝 App、確認／刷成 4.5.x，再開始改參數。

開始前：三條安全鐵則

1. 拆槳。任何在電腦前測馬達、測 failsafe、調參數的動作，槳一律拆掉。2. 先備份。接上飛控後先在 CLI 打 diff all，整段複製存成文字檔（用機號命名）。改壞了才有得救。

3. 一次只改一件事。改完存檔、記錄、再測。五台一起亂改，出問題找不到原因。

怎麼備份：Betaflight 的 CLI 分頁輸入 diff all → 按「Save to file」，或整段選取複製。 每台球機一個檔，檔名寫 機號＋日期（例：3號機_0726.txt）。

第一次連線檢查清單

  1. 拆槳；用可傳資料的 USB 線（不要用「只能充電」的線）。
  2. 開 app.betaflight.com → 選埠 → Connect。
  3. Windows 若找不到板子：裝飛控 USB 驅動（依板卡／晶片；常見要 STM／DFU 相關驅動）。
  4. 連上後立刻 CLI：diff all 存檔（機號＋日期）。
  5. 記下畫面的 Firmware version 與 Target，五台機各自建檔。本隊應為 4.5.x；若不是，交教練重刷。

刷飛控韌體（Firmware Flasher）

Configurator／App 是「調參遙控器」；韌體才是燒進飛控晶片裡、真正讓飛控會飛的作業系統。

本隊標準：學生機飛控統一刷 Betaflight 4.5.x（例如 4.5.1／4.5.2／4.5.3 等同系列；五台盡量同一小版）。

教練發機、收新板、救磚時，都刷回 4.5.x。不要為了追新把學生機升到 2025.12／RC——手冊數值、課堂示範、故障排除都以 4.5 為準。

刷錯 target 可能變磚。F411 ≠ RATE（AT32）≠ Oxbot（AT32 但 target 名不同），絕對不可互刷。

刷機常會清設定：先 diff all；刷完當新機重設。拆槳後再測馬達。

換版本時，設定能不能搬？

  • 4.3（或更早）→ 4.5：不要整份 diff／Preset 貼上。當新機重設。
  • 4.4 → 4.5：官方說多數飛行／Rx／Modes 可參考，但 ANGLE／HORIZON／GPS Rescue 必須用 4.5 新預設；仍以 Full erase＋對照手冊重設最安全。
  • 4.5.a → 4.5.b（同系列小升）：通常可保留設定，但仍建議先 diff all；有怪再 erase 重來。
  • 4.5 → 2025.12：當大搬家。Full erase、重對 Board Alignment、整本手冊流程重走；學生機本隊不做。

一句話記牢

  • 4.4＝現代刷機（Cloud Build）成型。
  • 4.5＝本隊戰場；自穩邏輯有改，球機功能齊。
  • 2025.12＝新世代＋新版號；功能多、變更多，學生機先別碰。
  • 4.5.1／.2／.3…＝修補號；全隊鎖同一個就好。

標準刷機步驟（雲端建置 Cloud Build）

4.4 之後官方用「線上依你選的板型與選項組出 hex，再燒進去」。球機日常照這條路即可。

  1. 開 app.betaflight.com → 左側 Firmware Flasher（韌體燒錄）。
  2. 飛控 USB 接上電腦。若還在一般模式，可先 Connect 做 Auto-detect；要刷機時再依畫面提示進入燒錄／DFU。
  3. 按 Auto-detect（自動偵測）。成功後核對板名／target 是否就是你手上那塊。
  4. 選 Firmware version：選 4.5.x（與隊上其他機同一小版最佳）。不要選 2025.12／RC／夜建。
  5. Build options／雲端選項：只勾這台用得到的（例如接收相關）。球機無圖傳／GPS，不要狂勾；F411（512K）勾太多會建置失敗。
  6. 勾選 Full chip erase（全晶片抹除）——發機、救磚、從非 4.5 刷回 4.5、建議都勾，然後當新機重設。僅同 4.5 小版熱修且有備份時，才由教練決定可不勾。
  7. 按 Load Firmware [Online]（線上載入韌體），等雲端建置完成。
  8. 建置成功後按 Flash Firmware。進度條跑完、顯示成功再拔線。
  9. 拔掉重插 USB → Connect。Setup 確認版本為 4.5.x 且 target 正確。

滑鼠移到已載入的線上韌體名稱上，有時可另存 hex，之後可用 Load Firmware [Local] 離線燒同一份——適合學校電腦網路不穩時，由教練先下載再發放。

進不了一般模式？用 DFU／Boot 鍵

DFU（Device Firmware Update）是飛控的「急救開機模式」：不跑舊韌體，只接受燒錄。

  1. 拔掉 USB 與電池。
  2. 找到飛控上的 Boot 按鈕（小按鍵，位置依板而異；看原廠圖）。
  3. 按住 Boot 不放 → 插入 USB → 再放開（有的板要插著再按，以原廠說明為準）。
  4. 在 App 的 Flasher 應看到 DFU 裝置。此時選對 target（Auto-detect 或手動），再 Load／Flash。
  5. CLI 若還連得上，也可試 bl（reboot to bootloader）再刷。

Windows 常見：裝置管理員出現「STM32 BOOTLOADER」卻無法刷 → 用 Zadig 替該裝置安裝 WinUSB（不要亂改成別的驅動）。刷完若一般模式又認不到，再依板子裝對 CDC／VCP 驅動。

AT32 板（RATE／Oxbot）的驅動與進 DFU 方式可能與 STM32 不完全相同，以原廠／Oxbot 知識庫為準；原則仍是：正確 target＋DFU＋好線。

刷完後一定要重做的事（當新機）

  1. Connect → Setup：確認 Firmware 版本；校正加速度計（平放）。
  2. Configuration：Mixer＝Quad X；關 MOTOR_STOP；開 AIRMODE／LED_STRIP／ANTI_GRAVITY（依手冊）。
  3. Ports：接收機 UART 的 Serial RX（Oxbot 內建 ELRS 勿照抄外接雙開）。
  4. Receiver：CRSF；Channel Map；檢查 AUX。
  5. Modes：ARM＝AUX1、PREARM、BEEPER、翻正…
  6. Failsafe＝DROP；拆槳測關遙控停槳。
  7. Motors：DShot300 起；轉向／順序；F411 原廠勿開 bidir。
  8. Power／LED／機名；再存一次 diff all（標明「刷機後」）。
  9. 完整走完 設定順序 與 上場前檢查 才裝槳。

和「電調刷機」的界線（F411 特別看）

飛控刷 Betaflight 不會自動把 BLHeli_S 變成可雙向 DShot。防守機 F411 若要 RPM 濾波，那是另一條路：電調刷 Bluejay、確認腳位與雙向是否真可用——見 三塊板差異 與「還有哪些沒寫」裡的電調刷機說明。不熟就維持原廠，不要賽前雙線開戰。

功能影響字典（每個設定到底動到什麼）

這一段不是要你背指令，是要你真的聽懂：這個旋鈕轉了，飛起來手感會變成什麼樣子。

每張卡都用「中文說明＋英文介面名稱＋對照位置／CLI」並列，你才能一邊看 Betaflight、一邊對得起來。

把整台球機想成一條流水線：你推遙控 → 接收機收到 → 飛控算該怎麼動 → 電調叫馬達轉 → 槳把球機推出去。每個設定都卡在這條線的某一個點；改錯點，整台就會飛得很怪，甚至危險。

怎麼對照：藍色那行是 Betaflight Configurator 的英文名稱與分頁位置；set xxx 是 CLI 指令。中文是給人看的感受說明，英文是給你在軟體裡找到同一顆旋鈕。

解鎖與安全：能不能轉、能不能安全關掉

解鎖開關ARM

對照位置：Modes 分頁 → ARM　｜　建議通道 AUX1（ELRS 官方建議）　｜　CLI 看 aux 設定

它在管

整台球機「准不准馬達轉動」的總開關。沒解鎖，推油門也不該轉；一上鎖，馬達要立刻停下來。

開的感覺

撥到解鎖，馬達開始怠速嗡嗡轉，你才推得動油門離地。撥回上鎖，四顆槳幾乎是瞬間停住，心裡會比較有底。

設錯會怎樣

沒設 ARM，或通道對錯，會一直解不了鎖，看起來像壞掉。更可怕的是：ELRS 官方要求 ARM 放在 AUX1，因為這個通道幾乎每個封包都會送。

你若把解鎖放在很後面的開關通道，訊號變差時，可能出現「想關關不掉、槳還在轉」的狀況。室內場地旁邊有人，這不能賭。

解鎖角度限制Small Angle / Maximum Arm Angle

對照位置：Configuration → Arming → Maximum Arm Angle　｜　CLI：set small_angle = 180（介面名稱與 CLI 變數名不同，改的是同一個）

球機為什麼要設

對抗中常在滾動、側倒、倒扣時要先上鎖（Disarm）停槳，再立刻解鎖（Re-Arm）接手。上鎖當下機身通常還是歪的——這就是需要放大解鎖角度的原因。

它在管

機身傾角超過此值就不准 ARM。官方預設約 25°：地上放平沒問題；滾動中再解鎖會一直卡死。Setup 上出現的旗標叫 ANGLE（意思是「不夠平」），不是 Modes 裡的 ANGLE 自穩飛行模式。

設成 180

等於關閉這項檢查，任意姿態都能再解鎖。官方也寫 180 可用於 crash 後翻正／再解鎖場景。球機比賽流程：滾動中 → Disarm 停槳 →（機身仍歪）→ Re-Arm 接手。

安全代價

180 等於倒著也能解鎖。地面側躺若誤觸 ARM，馬達可能往怪方向衝。

因此設 180 時 PREARM 強烈建議，並練成口訣：Disarm → 油門到底 → Re-Arm。詳見 空中再解鎖。

失控起飛保護Runaway Takeoff Prevention

對照位置：Configuration 分頁 → Arming　｜　CLI：set runaway_takeoff_prevention = ON

它在管

解鎖後如果飛控覺得「你根本沒要飛，但它自己暴衝」，會強制上鎖停槳。這是保護旁邊的人，不是保護成績。

開著的感覺

平常幾乎感覺不到它存在。真的遇到馬達順序錯、轉向錯、PID 爆掉那種「一解鎖就發瘋」的狀況，它有機會在事故變大前把槳停掉。

關掉會怎樣

少了一層救命網。尤其學生機、剛重焊過的機、剛改過馬達線的機，關掉等於拿安全換一個你幾乎用不到的「方便」。預設開著就對了。

加速度計校正Calibrate Accelerometer

對照位置：Setup 分頁 → Calibrate Accelerometer　｜　也會影響 ANGLE 自穩準不準

它在管

告訴飛控「什麼叫做水平」。ANGLE 自穩模式會一直想把機身拉回它認定的水平；水平基準歪了，整台自穩都會歪。

校正對的感覺

開 ANGLE 時，鬆開搖桿，球機會乖乖回正，懸停時比較不會一直往同一個方向偷偷爬走。你人站在旁邊看，機身視覺上也是平的。

校正歪會怎樣

你明明覺得自己放很平，飛起來卻一直往某一側「自己想飛」。新手會以為是 Rates 太靈敏或 PID 壞掉，其實常常只是校正時桌子不平、手碰到機、或球框本身翹著。

校正當下一定要平放、不要碰、等它跑完。

飛控安裝方向補償Board Alignment

對照位置：Configuration 分頁 → Board and Sensor Alignment　｜　CLI：align_board_roll / pitch / yaw

它在管

飛控板如果不是「箭頭朝機頭、平平正裝」，就要在軟體裡把角度補回來，讓飛控知道哪邊才是前面。

補對的感覺

你推俯仰，機頭就往前傾；推滾轉，機身就往側倒。大腦跟手是同一套邏輯，飛起來才學得會。

不補會怎樣

可能變成你推前，它往旁邊倒；你想左轉，它抬頭。這種錯位飛起來非常恐怖，幾乎沒有人能靠反應硬控。

焊完飛控第一件事就是確認方向，不確定就看 Setup 畫面：把機頭往前傾，畫面上也要同步往前傾。

不能解鎖原因看板Arming Disable Flags

對照位置：Setup 分頁的 Arming Disable Flags　｜　空中 Re-Arm 失敗時第一個看這裡

它在管

飛控直接告訴你為什麼不准解鎖：角度、油門、校正中、接收機……不是壞掉，是某道保護還沒過。

球機常見旗標

ANGLE＝傾角超過 small_angle（不夠平，不准 ARM；比賽設 180）。注意：這與 Modes 的 ANGLE自穩模式同名不同事。THROTTLE＝油門沒收到低於 min_check；CALIB＝感測器還在校正；還有 RX／CLI／MSP 等。

不看會怎樣

你會在錯誤的地方消耗整個下午，還可能把原本正常的設定改壞。空中解不開時，先記旗標再改設定。

空中 Disarm 後無法瞬間 Re-Arm（比賽致命）

球機標準救機流程：滾動／被撞／側倒中 → 先 上鎖（Disarm）停槳 → 機身往往還是歪的 → 立刻 再解鎖（Re-Arm）接手 翻正或飛走。

因此需要 small_angle = 180（Maximum Arm Angle）。若仍是預設約 25°，歪斜時會卡在旗標 ANGLE 解不開——對手球已經帶走了。

症狀：空中切上鎖後想立刻再解鎖，卻卡住 1～2 秒，甚至完全解不開。通常不是飛控壞掉，而是角度／油門／電調等安全條件還沒過。

操作口訣（肌肉記憶）：Disarm → 油門瞬間收到底 → Re-Arm → 再補油門。

不要油門還在半空就撥 ARM；也不要在機身還在狂轉的同一毫秒硬切（留約 0.1～0.2 秒讓積分清空）。

名稱別搞混：Setup 的 ANGLE 旗標＝「不夠平，不准解鎖」；Modes 的 ANGLE＝自穩飛行模式。兩者無關。

遙控、接收機、斷訊：你的手跟飛機中間那條線

接收機串列埠Serial RX

對照位置：Ports 分頁 → 對應 UART 那一列勾選 Serial RX　｜　焊在 RX2／TX2 通常就是 UART2

它在管

飛控有好幾個串列埠。你得告訴它：接收機的訊號線是接在哪一組 TX／RX 腳。

開對的感覺

Receiver 分頁的長條會跟著你的搖桿動，開關一撥就有反應。整台機「活過來」的感覺就是從這裡開始。

開錯會怎樣

開錯埠＝完全沒遙控，怎麼推都沒條。多開一堆用不到的埠也不好，平白佔資源，還可能跟別的功能打架。

Oxbot 若是內建 ELRS，接法跟外接接收機不一樣，不要照抄外接板的 UART 設定。

接收機協定Serial Receiver Provider

對照位置：Receiver 分頁 → Receiver Mode / Serial Receiver Provider　｜　CLI：set serialrx_provider = CRSF（ELRS／TBS）或 SBUS

它在管

接收機輸出的「語言」。ELRS、TBS Crossfire 這類通常是 CRSF；比較老的接收機才比較常看到 SBUS。

選對的感覺

通道乾淨、跟手，延遲低。你推搖桿，飛機幾乎是立刻應聲。

選錯會怎樣

通道會亂跳、卡死，或整排都沒訊號。看起來很像接收機壞掉或沒對頻，其實常常只是協定選錯。

對頻成功但 Betaflight 沒反應時，先查這一項。

通道對應與方向Channel Map / Stick Channel

對照位置：Receiver 分頁看 Roll／Pitch／Yaw／Throttle 長條　｜　CLI：map（例如 map AETR1234）

它在管

哪一根搖桿負責滾轉、俯仰、偏航、油門；推過去是正的還是反的。

對的感覺

推右滾轉，球機就往右側倒；拉俯仰，機頭就抬起來。大腦不用額外翻譯，身體記憶才建得起來。

反了會怎樣

一離地就往你指令的反方向衝，非常容易瞬間撞地或撞人。這不是「多練習就會」的問題，是設定錯，必須在桌上拆槳狀態先確認每根軸的方向。

接收機端斷訊行為RX Failsafe = No Pulses / No Signal

對照位置：不在 Betaflight 裡，在接收機／ELRS 設定　｜　正確是斷訊時不要繼續輸出最後搖桿值

它在管

遙控訊號不見時，接收機自己的行為。它可以選擇「什麼都不輸出」，也可以笨笨地繼續輸出最後一次的搖桿值。

設對的感覺

你把遙控器關機測試時，飛控很快就知道斷訊了，接著進入保護，馬達停轉。心裡會知道：真的出事時，它會停。

設錯有多可怕

如果接收機繼續輸出最後的油門與方向，飛控會以為「飛行員還在控」。結果就是：你遙控器沒電了、人或機被擋住斷訊了，球機卻還維持著最後的動作往前衝。

這是足球機最致命的設定錯誤之一，也是一定要拆槳實測關遙控器的原因。

飛控斷訊動作Failsafe Procedure = Drop

對照位置：Failsafe 分頁 → Stage 2 → Drop　｜　CLI：set failsafe_procedure = DROP

它在管

飛控確認「真的斷訊了」之後要做什麼。球機正確答案幾乎只有一個：DROP，立刻停槳上鎖，讓它掉下來。

DROP 的感覺

斷訊後馬達停，球機落地。不好看，但可控、可預期，旁邊的人知道它不會自己滿場亂飛。

用 Land／GPS Rescue 會怎樣

球機通常沒有 GPS，室內場地又小又有人。

Land 類的模式可能讓馬達繼續轉、繼續位移，看起來像「斷訊了還自己找地方落地」，實際上就是一台失控的旋轉刀具在場內移動。足球機不要用。

斷訊判定時間（Stage 1）Guard Time for Stage 2

對照位置：Failsafe 分頁 → Guard time for stage 2 activation　｜　CLI：set failsafe_delay = 15（單位 0.1 秒，15＝1.5 秒）

它在管

訊號開始怪怪的之後，要等多久才認定「真的斷了，進入停槳」。

較長的感覺

短暫被干擾、瞬間掉一兩個封包時，比較不會立刻掉機。對抗場地有金屬架、多人遙控同時在場時，這種容忍度有時有幫助。

較短的感覺

真的斷訊會更快停槳，安全性直覺上更高；但太短時，訊號稍微抖一下也可能誤觸發，比賽中突然掉機很冤。

建議

沒有特殊理由就維持官方預設。官方也提醒，低於約 0.2 秒會很容易被短暫掉訊誤傷。

先把接收機端 Failsafe 跟 DROP 做對，比糾結這零點幾秒重要太多。

模型配對Model Match

對照位置：ExpressLRS Lua／Web UI → Model Match　｜　這是 ELRS 端設定，不是 Betaflight 分頁名稱

它在管

遙控器當下選的模型檔，必須跟這台接收機對得起來，才允許控制。

開了的感覺

你拿錯模型檔時，這台球機不會理你。當下會覺得「怎麼連不上」，但其實是它在保護你，避免你控到別台、或用錯機的設定去飛。

不開的風險

五台球機外觀很像、同時在場邊充電待命時，最容易發生「我以為在控 3 號，其實訊號綁到 5 號」。

輕則嚇一跳，重則別人正在拿著那台機或有人靠近時突然轉槳。

封包率與連線預設Packet Rate + ExpressLRS Link Preset

對照位置：ELRS 端改 Packet Rate　｜　Betaflight → Presets 分頁搜尋並套用對應的 ExpressLRS Link

它在管

遙控器多常把你的手部動作送給飛控，以及這條無線連結在 Betaflight 裡該怎麼平滑、怎麼對延遲。

較高封包率

更跟手，動作比較「黏」在搖桿上；但在干擾多的場地，有時反而比較容易不穩。

較低封包率

抗干擾通常比較友善，連結較咬得住；手感上可能稍微沒那麼即時，但很多球類對抗其實更吃穩定，不一定要追最高。

常見坑

ELRS 端改了封包率，Betaflight 卻沒套對應的 ExpressLRS Link Preset，會出現遙控黏滯、飄、或反應不正確。

兩邊要一起看，不要只改一邊。

飛行模式：同一台機，開關一撥手感就換人

自穩模式ANGLE

對照位置：Modes 分頁 → ANGLE　｜　把某個 AUX 開關區間拉到 ANGLE 上

它在管

飛控會限制最大傾角，並且在你放掉搖桿時，努力把機身拉回水平。它吃的是「角度」，不是單純讓你自由狂轉。

開了飛起來

新手最有感：撞一下、慌一下、手忙腳亂放掉搖桿，球機還有機會自己回正繼續飛。練習懸停、左右橫移、基本頂球時，心理壓力小很多。

最大傾角預設大約 60 度，所以它不會讓你像特技機那樣整顆翻過去亂飛。

代價

動作天花板比較低。你想做很猛的側倒、快速翻轉、空中扭打，會覺得被什麼東西拉住，飛不久就會想切到 Acro。

依賴什麼

加速度計一定要校正準。校正歪了，自穩會「努力回到錯誤的水平」，看起來就像這台機有自己的主意，一直往某一邊爬。

特技／手動模式Acro（沒開 ANGLE 時的預設）

對照位置：不是單獨一個開關鍵　｜　Modes 裡沒啟用 ANGLE／HORIZON 時，就是 Acro

它在管

你推多少，它就依 Rates 去轉多少。你放掉搖桿，它大致維持當下的旋轉趨勢／姿態變化邏輯，不會像自穩那樣自動找水平。

飛起來的感覺

熟手會覺得世界打開了：翻滾、急轉、空中對抗都更自由，機子比較「聽你的」而不是「一直想幫你改動作」。

足球對抗到後來，很多攻擊手會待在這個模式。

新手常見狀況

一緊張就推過多，機身側過去以後自己回不來，接著越改越錯，最後落地或撞牆。不是機壞掉，是模式本身就不負責救你。

所以新進隊員先用 ANGLE，不是丟臉，是讓你活得下來才能練。

空中模式AIRMODE

對照位置：Modes 分頁 → AIRMODE，或 Configuration 常開　｜　CLI 也可相關 feature／模式設定

它在管

低油門、甚至油門收死的時候，PID 還要不要積極介入去穩姿態。球機對抗很常突然被撞、被壓、油門瞬間被你收掉，這一點非常關鍵。

開了的感覺

你被撞得往下掉、或自己急收油門時，機身比較不會立刻變成「失控自由落體亂翻」。空中還留著一點可控性，有機會把機頭扳回來再補油門。

關了的感覺

油門一收死，控制權像被抽走一半。碰撞後更容易進入亂滾，新手會覺得「怎麼一被撞就救不起來」。

翻正模式（烏龜翻）FLIP OVER AFTER CRASH

對照位置：Modes 分頁 → FLIP OVER AFTER CRASH　｜　需要 DShot；常見暱稱 Turtle Mode

它在管

球機四腳朝天或側翻掛住時，讓部分馬達反向轉，用推力把自己翻回正面。省得每次都跑進場撿。

成功時的感覺

倒地後撥翻正開關，機身扭一下翻回來，再切回正常模式就能繼續打。節奏快的對抗裡，這真的能救回一波球權。

千萬注意

一定要 DShot 才比較正常支援。更重要的是：槳如果卡死在球框、網子、地面異物上，你還硬開翻正，馬達／電調會在卡住的狀態猛出力，超容易燒。

卡死就停手，進去把槳解開，不要跟物理硬剛。

尋機蜂鳴BEEPER

對照位置：Modes 分頁 → BEEPER　｜　LED 視覺蜂鳴：CLI set ledstrip_visual_beeper = ON

它在管

讓你在場邊用聲音或燈光找到球機。球一飛遠、滾到擋板後、或鑽進場邊雜物區時超有用。

有的感覺

撥尋機開關，聽到滴滴叫或看到燈在閃，整隊不用像找走失寵物一樣滿場爬。比賽換場、練習收操時特別感恩。

沒裝蜂鳴器

至少把 LED 視覺蜂鳴打開，讓燈幫你閃。總比完全沒提示好。

馬達與電調：指令有沒有被正確變成推力

電調通訊協定ESC/Motor Protocol

對照位置：Motors 分頁 → ESC/Motor Protocol　｜　CLI：set motor_pwm_protocol = DSHOT300 或 DSHOT600

它在管

飛控跟電調溝通的數位語言。比起老式類比油門訊號，DShot 比較抗干擾，也才方便做 Turtle、雙向轉速回傳這類功能。

用起來的感覺

油門反應乾淨，功能也比較齊。一般球機用 DShot300 很穩；線路好、飛控也撐得住再考慮 DShot600。

選錯會怎樣

電調不支援你選的協定時，馬達可能不轉、亂跳，或解鎖後行為怪異。

這時不要先懷疑 PID，先回到 Motors 分頁確認協定跟電調實際能力。

馬達順序與轉向Motor Order / Direction

對照位置：Motors 分頁逐顆測試　｜　轉向可在電調設定（BLHeli／Bluejay／AM32）反轉，或資源對應調整

它在管

飛控以為自己在叫「左前加快」，實際上加快的必須真的是左前那顆，而且旋轉方向還要符合你選的 Props In／Props Out 圖。

全對的感覺

輕輕推油門，球機平平離地；推滾轉、俯仰，方向正確且力量對稱。你會覺得這台機「很聽話」。

錯了有多明顯

幾乎是一開油門就翻、原地轉、或往奇怪方向彈出去。這不是手殘，是設定／接線邏輯錯。

標準流程一定是：拆槳、Motors 分頁逐顆點、看實際哪顆在轉、再對圖檢查轉向。不要裝著槳在那邊賭。

雙向 DShot（轉速回傳）Bidirectional DShot

對照位置：Motors／Configuration 相關開關，或 PID Tuning 濾波區　｜　CLI：set dshot_bidir = ON

它在管

讓電調把每顆馬達當下轉多快，回傳給飛控。有了真實 RPM，才能做比較聰明的 RPM 濾波跟 Dynamic Idle。

開得成的感覺

後面濾波與怠速相關功能才有意義。對抗時震動大、常撞、常急停，開對了通常會明顯比較穩、比較不容易莫名失步。

硬體不支援卻開

最常見後果是馬達不起轉、解不了鎖、或狀態怪異。本隊 HAKRC F411 原廠 BLHeli_S 就是這情況：不是「RPM 濾波邪門」，是原廠韌體根本沒有合格的雙向回傳能力。

RATE／Oxbot 這類 32bit 電調才比較適合直接開。

馬達磁鐵數Motor Poles

對照位置：Motors／Configuration 或 PID 相關區塊　｜　CLI：set motor_poles = 14（請實際數磁鐵）

它在管

飛控要靠磁鐵數，才能把電調回傳換算成正確轉速。14xx／15xx 馬達很常見是 14，但還是要實際數鐘罩內磁鐵，不要用猜的。

填對的感覺

RPM 濾波會打在正確頻率上，震動被清掉的是該清的，手感比較乾淨。

填錯會怎樣

飛控很認真地濾錯頻率，該留的訊號被傷到、該濾的噪音還在。結果常常是更抖、更難飛，然後有人又去猛加 PID，整台越調越糟。

怠速／最低油門Motor Idle / DShot Idle Value

對照位置：Motors 分頁 → Idle／DShot Idle　｜　CLI：set motor_idle = ... 或對應 dshot idle 設定

它在管

解鎖之後、你油門還在最低時，馬達不是歸零死停，而會維持一個基本轉速。這個基本轉速會大幅影響「收油後的穩定性」跟「能不能剎得住」。

怠速偏高

馬達比較不容易在急停、翻滾、被撞後失步停轉；但低油門會比較「浮」，收油剎不住、倒飛掛空感變差，也比較耗電。

怠速偏低

收油比較利、比較乾脆，直線煞車與快速變向會比較痛快；但太低時，翻滾中段或突然反向氣流一來，馬達可能轉太慢甚至停轉，接著就是失步、失控那一套。

動態怠速Dynamic Idle

對照位置：PID Tuning 分頁 → Dynamic Idle　｜　CLI：set dyn_idle_min_rpm = ...，並 set transient_throttle_limit = 0

它在管

有雙向 DShot 時，飛控可以看著真實轉速說：「這顆太慢了，我幫你補一點，不要停死。」這樣就不用把固定怠速拉得很高。

開對的感覺

急停、快速翻面、空中被撞後再補動作，比較不容易突然某一顆馬達失步。

同時因為不必靠很高的固定怠速，收油時又比「整段怠速都偏高」更乾脆。

前提與坑

沒有雙向 DShot 就不要幻想它有用。官方也要求搭配時把 transient_throttle_limit 設成 0。

數值不能抄 5 吋穿越機就結束：球機槳比較小、轉速區間不同，最好自己量怠速 RPM，再抓一個略低、但不會失步的點。

油門上限Throttle Limit

對照位置：PID Tuning → Rates → Throttle Limit　｜　CLI：set throttle_limit_type = SCALE、set throttle_limit_percent = 80

它在管

把你遙控器油門的可用行程壓縮或封頂。新手練習、大推力機（如 1507）很常用。

SCALE 的感覺

整支油門行程被拉長：推到底也到不了真・100%。懸停附近更好控，比較不會輕輕一推就頂天花板。

比賽忘記改回

衝刺、射門、快速拉升都會變肉。看起來像電池沒力或馬達弱，其實只是軟體還鎖著。練習機可以鎖，正式上場前記得改回 OFF。

油門中點（假定高手感核心）Throttle Mid

對照位置：PID Tuning → Rates → Throttle → Mid　｜　CLI：set thr_mid = 45（介面常顯示 0.45）

它在管

油門曲線的「彎折中心」。你要把這個點對準自己實際懸停時的油門位置，懸停附近才會最好控。

對準的感覺

搖桿停在懸停附近時，微幅上下晃，高度不會一下子衝一下掉。體感很像「有定高」，但其實只是曲線被壓平了。

設錯會怎樣

Mid 設太低或太高，平緩區會偏離真正懸停點，你反而要一直補油門，手感比沒調更怪。一定要先飛測懸停％，再填數字。

防守特別重要

防守要控場、追球、卡位，油門幾乎一直待在懸停附近。Mid 沒對準，整場都會忽上忽下——這對防守球員幾乎是必調項。

油門曲線／展幅Throttle Expo

對照位置：PID Tuning → Rates → Throttle → Expo　｜　CLI：set thr_expo = 40（介面常顯示 0.40）

它在管

在 Mid 附近把油門響應「壓平」的程度。Expo 越高，懸停區越鈍、越細膩；外側仍可推到較大推力。

0.30～0.50 的感覺

懸停微調變友善，不容易忽上忽下。新手與大推力攻擊機特別有感。

防守怎麼設

防守優先把 Expo 拉到 45～50，讓懸停區更平。攻擊可略低（35～45），因為更常打高油門衝刺。

太高／太低

Expo＝0 是接近線性，懸停區很跳。Expo 拉太高，要突然爬升或射門時會覺得油門「後半段才突然用力」，需要再微調回舒服點。

假定高油門手感（不是真定高）

防守球員：這一項幾乎是必調。

防守要長時間控場、追球、卡位、小幅平移——油門一直在懸停附近晃。Mid／Expo 沒對準，高度就會忽上忽下，看起來像手抖、像機不穩，其實是油門曲線沒幫你。

攻擊手衝刺射門時比較常打高油門，假定高有幫助但沒那麼致命；防守手沒調好，整場都會難飛。

先講清楚：足球機用的 Betaflight，預設是手動油門（Acro／Angle）。

它沒有像消費級航拍機那樣靠氣壓計或超音波「鎖住高度」的真定高。室內氣壓亂，也不該靠 Baro／Altitude Hold 打球。

你要的其實是：懸停附近油門不敏感、不容易忽上忽下——這靠 Throttle Mid＋Throttle Expo（必要時再加 Throttle Limit）就能做出非常接近「定高」的體感。

第一步：找出你的懸停油門位置

拆槳以外的真實飛行測試：讓球機平穩懸停，看 OSD／黑匣子／遙控器油門％（Throttle %）。

機況常見懸停油門說明
較重（接近 300g、22cm 球框、攻擊大電池）40%～50%1507／DYH1408＋4S 高 C 常見落在這帶
較輕（防守輕配、3S／小電池）25%～35%輕機懸停點比較低
電量變低時會往上漂電壓掉了，同樣高度需要更高油門％；調參時用「半電～七成電」測比較準

記下這個數字。例如懸停在 45%，下一步就把 Mid 對準 45%。

五台機重量／槳／電池不同，不要抄同一組 Mid；每台自己測。

第二步：在 Betaflight 設 Throttle Mid／Expo

打開 Configurator → PID Tuning → Rates 頁籤，找到右側（或下方）的 Throttle：

項目介面怎麼填CLI 怎麼寫球機建議
Throttle Mid 設成你測到的懸停點，例如 0.45 set thr_mid = 45 對準該機真實懸停％；攻擊重機常 40–50，輕機常 25–35
Throttle Expo 先試 0.30～0.50 set thr_expo = 30～50 防守優先調高（先 45～50）；攻擊可 35～45。越高＝懸停區越平緩
Throttle Hover（thr_hover） 可填接近懸停％ set thr_hover = 45 給部分內部估算用；不會讓球機真定高。手感仍靠 Mid＋Expo

原理（一句話）：Expo 把 Mid 附近的油門變化壓平；搖桿在懸停點附近微動時，馬達轉速幾乎不太變，高度就穩很多。

外側推高時仍可要到較大推力，所以不是把整台機「鎖死變肉」，而是把懸停區變細膩。

# 範例：某台攻擊機測得懸停約 45%
set thr_mid = 45
set thr_expo = 40
set thr_hover = 45
save

遙控器端（OpenTX／EdgeTX，可選）

若你習慣在 Radiomaster 等遙控器調曲線，也可以對油門（Thr）做 S 曲線，把中央拉平在懸停附近。

不要兩邊疊太兇：飛控已設高 Expo，遙控器再加一條很平的 S 曲線，懸停會變得過度遲鈍，要突然爬升時會「推了半天沒反應」。

本隊建議：優先只改 Betaflight 的 Mid／Expo；遙控器曲線當進階選項，且一次只動一邊。

做法適合誰注意
只改 BF thr_mid／thr_expo全隊統一、最建議換遙控器也不會手感跑掉
遙控器 Thr S-Curve同一支遙控打多台、或暫時不想改飛控換機／換模型檔要記得曲線也換
兩邊都大調通常不建議難追溯、容易過度平緩

調完怎麼驗收

防守手驗收標準更嚴：要能在半場高度穩穩「站住」，左右橫移追球時幾乎不用狂修油門；被撞一下後補油門回來，高度也不應暴衝。

  1. 半電狀態，懸停 10～20 秒：手微微抖，高度不應明顯抽動。
  2. 從懸停輕推爬升、再收回：過渡要順，不要「後半段突然噴」。
  3. 做左右橫移與小幅頂球／卡位：油門不必一直狂修（防守必測）。
  4. 若仍忽上忽下：先確認 Mid 是否真的對準懸停％，再小幅加減 Expo（一次 ±5；防守可往 50 靠）。
  5. 練習若有開 SCALE，比賽前改回 throttle_limit_type = OFF。

吸網效應（Wall／Mesh Effect）

這不是遙控干擾。球機貼近球網或牆面時被「吸住」、油門推到底也拔不開——多半是氣流造成的物理吸附（白努利／高低壓差，也常跟 Coandă 效應一起被討論）。

不懂原理就死推油門，通常會吸得更緊，甚至把 I-Term 飆滿、馬達過載發燙。

一、硬體：推力與球籠

為什麼攻擊常選 1507：吸網後的低壓＋風阻，小扭力馬達（如部分 1408 輕配）滿油門也可能掙脫不開。

1507／同級大推力的瞬間爆發（punch-out）比較有機會強行拉開吸力。防守用較小馬達時，更要靠手法與參數，不能只靠硬衝。

  • 攻擊／硬頂：優先 火神 VCI 1507 或同級高推力＋高 C 電池（見馬達章）。
  • 球籠外側摩擦力越大越容易卡網；有隊伍會在外層噴薄薄乾式矽光油或光滑塗層（注意規則／檢錄，勿厚塗增重）。
  • 槳裂、球籠變形會讓氣流更亂，吸網與震動都會變糟——先修硬體。

二、Betaflight：Anti Gravity＋限制 I 累積

貼網時姿態誤差一直在，I-Term 容易累到接近飽和。搭配較積極的 Anti Gravity，急推／點噴油門時比較不會又點頭又瘋轉。

CLI 名稱：截止頻率是 anti_gravity_cutoff_hz，不是 anti_gravity_cutoff_freq。

改完若出現催油劇烈晃動，先把 gain 往回降（例如 200→150），不要硬留在上限。

三、操作連招（隊員必練）

錯誤：一直滿油門硬衝 → 低壓更穩、吸得更死。

連招動作原理
A. 點噴油門
Throttle Tapping		 瞬間點一下接近滿油 → 立刻收油 → 再點一下（可重複） 短促大推力打破低壓平衡；收油瞬間壓力恢復，機較易離網下落
B. Disarm／Re-Arm 閃脫 吸住瞬間：Disarm → 油門到底 → 零點幾秒內 Re-Arm → 補油

閃脫前必須已設好空中再解鎖（角度 180、油門到底習慣），否則 Disarm 後會解不回來，比吸網更糟。

PID、濾波、Rates：手感從哪裡來

先講清楚先後順序：槳裂、螺絲鬆、減震球沒裝好、馬達鈴歪，這些硬體問題不修，調 PID 只是在幫噪音「追得更用力」。先讓機身乾淨，再談手感。

比例增益P Gain

對照位置：PID Tuning 分頁 → Profile → P（Roll／Pitch／Yaw）　｜　CLI：set p_pitch / p_roll / p_yaw

它在管

飛控發現「現在姿態跟你要的不一樣」時，第一時間要補多用力。

調高的感覺

更跟手、機身比較「硬」、指令一到就往上貼。對抗時被撞一下，回正會比較乾脆。

調低的感覺

變軟、變慢半拍，像方向盤有點空。你推了，它好像想一下才動。

太高會怎樣

開始出現高頻抖動，機身在震、馬達聲音變尖。這時若還繼續加，只會更抖更熱。

積分增益I Gain

對照位置：PID Tuning 分頁 → Profile → I　｜　CLI：set i_pitch / i_roll / i_yaw

它在管

如果誤差一直存在，例如被風吹、被頂著、重心略偏，I 會持續累積修正，把機身慢慢扳回你要的狀態。

調高的感覺

比較貼指令，不太會慢慢漂走。懸停、對抗時被人持續擠壓，比較有「頂得住」的感覺。

調低的感覺

短時間還好，但飛久一點會發現它慢慢偏離，要你一直微調才能維持姿勢。

太高會怎樣

低速時容易晃、回彈，像有人在後面輕輕推來推去。看起來很不穩，但其實不一定是 P 的問題。

微分增益D Gain

對照位置：PID Tuning 分頁 → Profile → D　｜　CLI：set d_pitch / d_roll（Yaw 通常較特殊）

它在管

當機身正在快速晃、或動作要衝過頭時，D 負責把這股「過頭的動能」壓下來。

調高的感覺

比較穩，翻滾停得比較乾淨，被撞後比較不會彈兩下才停。整體看起來比較「收得住」。

調低的感覺

動作比較容易過一下再回來，像煞車偏軟。輕微時只是不夠俐落，嚴重時會一直小抖。

太高會怎樣

馬達變吵、變熱，像一直在追高頻噪音。D 太高是燒馬達、燒電調的常見原因之一，尤其在濾波沒做好的時候。

前饋Feedforward (FF)

對照位置：PID Tuning 分頁 → Profile → Feedforward　｜　CLI：set f_pitch / f_roll / f_yaw

它在管

不等誤差變大，只要看到你搖桿開始動，就先預估你要轉，提前叫馬達出力。它追求的是「更跟手、更少滯後」。

適中的感覺

推什麼就去什麼，手跟機之間的黏稠感變少，轉彎切入比較乾脆。

太高會怎樣

會有「超前」感，像機子比你更急，容易過衝再被 PID 拉回來。球機通常先用官方預設就好，不要一開始就拿 FF 賭手感。

抗重力（油門劇變補償）Anti Gravity

對照位置：PID Tuning → Anti Gravity　｜　CLI：set anti_gravity_gain = 250、set anti_gravity_cutoff_hz = 15

它在管

你突然大腳油門或突然收油時，機身很容易點頭、翹尾。Anti Gravity 會在油門劇變時暫時加強修正，把姿態留住。

開著／加強的感覺

衝刺射門、碰撞後補油、以及吸網點噴脫困時，過渡比較乾淨，比較不會先栽頭再起來。

關了／太弱

一催油就點頭，一收油就翹。貼網點噴時也更容易失控。

吸網向調法

預設 gain 約 80；吸網向可試 200～250，cutoff 10～15 Hz。催油開始劇晃就往回降。截止頻率 CLI 是 anti_gravity_cutoff_hz。

I 項防飽和（貼網）I-Term Windup

對照位置：PID Tuning 進階／CLI　｜　set iterm_windup = 40

它在管

馬達輸出接近飽和時，還要不要繼續讓 I 積分往上堆。數值愈低，愈早開始抑制 I 累積。

貼網時調低的感覺

被網卡住、姿態到不了目標時，比較不會把 I 飆到讓馬達發瘋空轉／過熱。

太低

正常飛行抗持續外力（被人頂著）可能變弱。球機吸網向常見 40～50；若空中變「頂不住」再略調回。

陀螺儀／D 項濾波Gyro Filter / D Term Filter

對照位置：PID Tuning 分頁 → Filter Settings　｜　含 Dynamic Notch、D term LPF 等；先維持預設

它在管

飛控陀螺儀很敏感，槳、馬達、球框共振都會製造高頻噪音。濾波的工作就是：真實姿態留下，雜訊丟掉。

濾太重

手感變鈍，像隔著一層布在飛。你推了，它慢半拍才到；看起來很穩，但其實犧牲了很多跟手程度。

濾太少／亂關

PID 開始追噪音，馬達尖叫、發燙，嚴重就燒電調。

有些人為了「延遲低一點」把濾波砍光，這在球機上非常不划算，因為球框與碰撞本來就更髒、更震。

RPM 濾波RPM Filter

對照位置：PID Tuning 分頁 → Filters → RPM Filter　｜　前提：dshot_bidir = ON，且 motor_poles 填對

它在管

知道馬達現在轉多快之後，飛控可以精準地對準那些跟轉速綁在一起的震動頻率來濾，而不是整段頻率一把抓。

開對的感覺

機身乾淨很多，其他濾波往往可以不用拉得那麼重，所以常常同時得到「更穩」跟「比較不鈍」。對抗這種高震動場景特別有感。

開錯前提

沒雙向 DShot、電調不支援、或 motor_poles 填錯，效果就會走鐘：輕則沒幫助，重則不起轉或更抖。

不要聽別人說「足球機一定要開」就無腦開，先看你那塊板辦不辦得到。

中心靈敏度RC Rate / Center Sensitivity

對照位置：Rateprofile／PID Tuning → Rates　｜　ACTUAL 模式下對應中心速度；CLI：roll_rc_rate / pitch_rc_rate / yaw_rc_rate

它在管

你只輕輕推一點點時，飛機要轉多快。這直接決定「微調好不好做」。

偏高的感覺

輕輕碰搖桿就有明顯動作，看起來很靈，但懸停、對球、小幅平移會變難，手一緊張就推過頭。

偏低的感覺

中間很好控，像有緩衝區；可是你想做小幅度快速修正時，要推更多才有反應。很多人練球機會先把中間降到自己不會手抖亂飛。

最大轉速Max Rate / Super Rate

對照位置：Rateprofile → Rates 圖右側最大 deg/s　｜　CLI：roll_srate / pitch_srate / yaw_srate（依 rates_type）

它在管

極限動作有多猛。打滿滾轉／俯仰時，機身翻面、變向的速度上限就在這裡。

偏高的感覺

空中可以很快翻面、扭身、做比較激烈的脫身。上限高，但容錯低，一下子就轉過量。

偏低的感覺

整台變得比較溫馴，室內很好練；可是到了要快速擺脫纏鬥、快速調整機頭方向時，會覺得「轉不夠快」。

怎麼調比較合理

先低後高。先找到你不會暈、不會一直撞的範圍，再慢慢往上加。不要一開始就抄競速機那種又高又兇的 Rates。

曲線緩和RC Expo

對照位置：Rateprofile → Expo　｜　CLI：set roll_expo / pitch_expo / yaw_expo

它在管

搖桿行程的手感曲線。加 Expo 通常是讓中間更細膩，但外側打滿還是能到你設定的最大轉速。

加一點的感覺

懸停與微調變友善，不容易在中間區域抖動就越修越大；需要大動作時，還是可以把搖桿推出去用滿。

完全線性

好預測，但也比較「直」，新手在中間區容易覺得太跳。有人喜歡線性，有人喜歡中間軟一點，這沒有標準答案，屬於個人手感。

自穩最大傾角Angle Limit

對照位置：PID Tuning → Angle mode 相關　｜　CLI：set angle_limit = 60

它在管

ANGLE 模式下，飛控允許的最大傾斜角度。預設大約 60 度。

調大的感覺

自穩也能側得比較兇，左右橫移、壓低機身衝刺會比較有力。

調小的感覺

整台更「平飛」，較不容易側翻失控；但橫向移動與壓角度過彎會變慢、變肉，像被限制在一個淺淺的碗裡飛。

電池、電流、燈光：你看不看得到「該停了」

電壓校正Voltage Scale

對照位置：Power & Battery 分頁 → Voltage Meter → Scale　｜　CLI：set vbat_scale = ...

它在管

飛控自己量到的電池電壓，跟真實電壓中間的比例關係。不校正，後面所有低壓警告都是在猜。

校正準的感覺

紅閃與警告會在對的時間出現。你開始相信燈光，該換電池就換，電池也比较不容易被打穿。

偏高／偏低

飛控以為電壓比實際高：警告太晚，電池已經受傷你還在打。飛控以為電壓比實際低：才飛一下子就紅閃，整隊會覺得續航很差、一直換電池。

兩種都很煩，而且都會讓你做出錯誤判斷。

警告電壓／最低電壓Warning / Minimum Cell Voltage

對照位置：Power & Battery 分頁　｜　CLI：set vbat_warning_cell_voltage = 350、set vbat_min_cell_voltage = 330（單位 0.01V）

它在管

什麼時候開始提醒你「電不夠了」，什麼時候算危急。球機沒有圖傳 OSD，這件事通常得靠 LED 紅閃或其他提示表現出來。

設得合理時

對抗打到後段，燈開始警告，你還有時間把球權處理完再下場換電，不會突然整台無力墜機，也不會默默過放。

設太低／太高

太低：燈都不叫，電池已被虐到後續容量與壽命變差。太高：每場飛一下就警報，節奏破碎，隊員開始不理會警告，久了反而更危險。

電流計比例Current Meter Scale

對照位置：Power & Battery 分頁 → Current Meter → Scale　｜　CLI：set ibata_scale = ...（F411 常見 210）

它在管

飛控怎麼把感測到的訊號換算成「現在抽了多少安培」。它影響耗電估計、黑匣子曲線，也影響你對這台機「吃不吃電」的判斷。

準的時候

你看得出哪種飛法特別耗電，調完槳、換馬達、改飛法之後也比較知道有沒有變兇。

不準時

你可能以為這台很省電其實很兇，或相反。它通常不會立刻讓你墜機，但會讓教練跟隊員對續航做出錯誤結論。

HAKRC F411 常見要確認原廠比例（例如 210），別的板則要實測。

電池容量Battery Capacity

對照位置：Power & Battery 分頁 → Capacity　｜　CLI：set bat_capacity = 1060

它在管

給飛控一個「這顆電池大概有多大」的參考，方便估算剩餘百分比。

填對的用途

看百分比比較有意義，尤其你有在看黑匣子或後台紀錄時。

填錯也不會改變推力

它不會讓馬達變強或變弱。只是參考值變差。真正決定能不能飛、安不安全的，還是電壓校正跟低壓警告。

燈條功能與亮度LED_STRIP / LED Strip Brightness

對照位置：Configuration → Features → LED_STRIP；LED Strip 分頁調色　｜　CLI：feature LED_STRIP、set ledstrip_brightness = 40

它在管

飛控要不要控制燈，以及燈要亮到什麼程度。亮度直接等於耗電，也直接等於 BEC 壓不壓得住。

亮麗的代價

場上很好認、很好看，攝影師也喜歡；但 22 顆燈全開到很亮時，小 BEC 會喘不過氣，可能造成壓降、飛控重啟、莫名斷控。

看起來像飛控有鬼，其實是電力被燈吃垮。

適當調暗

還是看得到隊色與射手燈，但整台電力餘裕變大，飛起來比較安穩。F411 這種比較小的 BEC，務實一點，亮度乖乖降。

低壓警示燈／視覺蜂鳴Battery Warning + Visual Beeper

對照位置：LED Strip 分頁功能色／警告色　｜　CLI：set ledstrip_visual_beeper = ON，並設好警告電壓

它在管

把電池警告變成你在場上用肉眼就看得懂的訊號。沒有圖傳螢幕的球機，這幾乎是唯一即時警示。

有設的感覺

打到後段燈一變，替補就知道該準備換電；飛行員也知道該收，不要再硬打一波猛攻。

沒設的結果

大家憑感覺飛，感覺通常會騙人。結果就是某台機突然無力、過放、或飛到一半電子行為開始怪異，事後才在那邊猜是不是電池問題。

圖傳供電關閉VTX BEC OFF

對照位置：Oxbot 板專用開關／說明（視韌體與板載選項）　｜　沒裝圖傳務必關閉，避免空接供電

它在管

有些飛控板即使你沒插圖傳，圖傳那一路供電還是可能活著。關掉它，就是把用不到的電力與風險拿掉。

關掉的好處

少耗電、少發熱、少一個可能製造干擾的電源路徑。球機本來就沒圖傳，開著常態供電沒有好處。

沒關會怎樣

不一定馬上壞，但屬於「明明用不到卻一直開著」的風險與浪費。能關就關。

黑匣子與其他：幫你找問題，不是讓飛更好看

黑匣子紀錄Blackbox

對照位置：Blackbox 分頁 → 開啟／關閉與記錄裝置　｜　CLI：set blackbox_device = SPIFLASH 等

它在管

記錄陀螺儀、馬達輸出、PID 行為等資料，讓你事後在電腦上看「當時到底為什麼抖、為什麼飄」。

調參時開

非常有價值。你可以看見震動頻率、馬達是不是在追噪音、油門一催姿態怎麼掉。這比憑感覺吵架準太多。

平常建議關

一直開會吃儲存空間跟系統資源。你若從來不看紀錄，開著只是增加負擔，對比賽本身沒幫助。

機號命名Craft Name

對照位置：Setup／Configuration 可見名稱，或 CLI　｜　CLI：set craft_name = CHSH-1

它在管

這台飛控在 Betaflight 裡顯示的名字。五台球機外觀愈像，這個愈重要。

有命名的好處

USB 一插就知道是 3 號還是 5 號，不會改錯機、備份也不會存錯檔。教練在場邊排障時會省很多命。

不設的後果

大家憑記憶跟貼紙辨認，最後一定會有人把 A 機的參數貼到 B 機，然後說「奇怪怎麼愈改愈糟」。

通常不用開的功能OSD / GPS / Baro / 3D

對照位置：Configuration → Features：OSD、GPS 等；Modes 的 GPS 相關模式；Configuration 的 3D　｜　球機沒硬體就不要開

OSD

是圖傳畫面疊字。沒鏡頭、沒圖傳就看不見，開了也只是多一層負擔。

GPS／氣壓計

有硬體才有意義。沒裝卻開啟相關模式，常會多出錯誤、延遲或莫名其妙的限制。

3D 模式

那是讓馬達可正反轉做特定特技用的。球機不需要；還可能跟 Dynamic Idle 這類功能衝突。看到就略過，不要因為名字酷就打開。

最後用大白話收斂一次： Rates 決定「好不好控、轉得快不快」； PID 決定「跟不跟手、穩不穩、會不會過衝」； Filters 決定「噪音清不清，馬達會不會去追雜訊」； ARM／Failsafe 決定「出事時能不能停下來」； 電池與 LED 決定「你知不知道該換電，以及燈會不會把電力吃垮」。

調之前先問自己：我現在到底想改哪一種感覺？不要為了改而改。

建議補進流程（球機真的用得到）

中文英文／位置建議為什麼先前容易漏、但很重要
預解鎖 Modes → PREARM 建議加在另一個開關：要先 PREARM，再 ARM 才轉 學生機最實用的防呆。遙控器在包包裡被擠到 ARM，若沒有 PREARM，可能直接轉槳。室內場地旁邊都是人，這層開關很值得
馬達停止功能 Configuration → Features → MOTOR_STOP 通常保持關閉（OFF） 開著時，油門收到最低會直接停轉。聽起來安全，但跟 Airmode／對抗中的姿態控制衝突，常飛起來很怪。球機一般維持 OFF，靠 ARM 上鎖才真正停槳
槳向圖（內八／外八） Motors → Props in / Props out 全隊統一一種，本隊先定一種後不要混 只講「轉向要對」還不夠。你選的圖，必須跟四顆馬達實際轉向一致，不然會以為轉向對了其實整體扭力邏輯是反的
機架型式 Configuration → Mixer → Quad X Quad X 足球機就是標準四軸 X 字。若被改成別的 mixer，馬達邏輯全錯，一開油門就翻
馬達蜂鳴尋機 Configuration／Beeper → DShot Beacon；Modes 也可配 BEEPER 建議開；找機時很有用 沒裝獨立蜂鳴器時，可用 DShot Beacon 讓馬達發出滴滴聲找機。球滾到擋板後超實用。注意：尋機時槳有機會微動，周圍要淨空
特技訓練器 Modes → ACRO TRAINER 新手練 Acro 時很有用 讓你在 Acro 手感下，仍限制最大傾角，比較不會一緊張就整顆翻過去。比直接丟進全開 Acro 溫和，比一直待在 ANGLE 又更接近實戰
偏航失控保護 PID Tuning／Features → Yaw Spin Recovery 建議維持 ON（多數新版預設就有） 某顆馬達失步開始瘋狂自轉時，飛控會介入嘗試停損。對抗碰撞多，這類保護比穿越機更有感
遙控死區 Receiver → Deadband 先 0–2；搖桿有漂才加 搖桿中位若微微漂，球機會自己慢慢爬走。死區太大會變得不跟手；先確認遙控器校正，再考慮加一點點
搖桿行程端點 Receiver 看 1000–2000 最低近 1000、最高近 2000；中位約 1500 行程不夠，你會覺得油門推到底還不夠力、或某個方向轉不滿。這常被誤判成 Rates／馬達問題
蜂鳴器哪些狀況要叫 Configuration → Beeper Configuration 保留電池警告、Failsafe、尋機；可關 USB／開機嗶嗶 桌上調參一直叫會讓人把蜂鳴器關掉，結果上場真正低電壓也不叫。要關只關「煩的」，不要關「要命的」
射手機色一鍵切換 Modes 的 LEDLOW／使用者模式，或硬體／AUX 切色 本隊規則需要時要有方案 中場不能接電腦改射手尾燈顏色。這不是可有可無，是比賽流程功能。細節也寫在 LED／規則頁，飛控端要預留開關或備機
陀螺儀校正 Setup 靜置；可選 Gyro Calibration on First Arm 開機後先平放靜置；必要時開首次解鎖校正 前面強調加速度計很多，陀螺儀也要穩。開機後馬上拿著晃，校正品質會差，飛起來會飄、會漂
RC 平滑／連線預設 Presets → ExpressLRS Link；Receiver 的 RC Smoothing 改完 ELRS 封包率一定要套對應 Preset 只改 ELRS 不改 BF，常出現黏滯、頓挫。這點前面有提，但要當成「改遙控必做步驟」而不只是選配
電調刷機路徑（F411） Motors → ESC Pass-through → Bluejay 等 只有要上雙向 DShot／RPM 濾波時才做 原廠 BLHeli_S 不能雙向。若防守機也想開 RPM 濾波，得走刷 Bluejay／確認腳位這條路，不是在 BF 勾一個選項就結束。這與飛控刷 Betaflight是兩件事

名詞統一：射手 ＝ 攻擊手 ＝ 前鋒（striker）——同一個角色、同一台球機，不是三種人。本頁以下一律稱 射手。

規則重點：每隊只有 1 名射手，也是唯一可以得分的人；其餘隊員只能防守／導引。

亮度與電量粗算（22 顆）

結論：續航幾乎都是馬達吃掉的；調 LED 亮度對飛多久影響通常 <3%（約 1–2 秒）。 調暗主因是不刺眼、BEC 較不熱。

① 單顆 WS2812

  • 全亮白光約 60 mA＠5V（約 0.3 W／顆）。
  • 純紅或純藍約白光的 1／3（約 20 mA＠5V）。

② 本隊：買 1m／60 燈條，只裝 22 顆
