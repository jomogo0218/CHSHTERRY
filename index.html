嘉華中學足球無人機俱樂部

明天介紹請照下方「講課順序」走：先看比賽 → 新手圖文認識零件 → 分清規則雙軌 → 本隊定稿 → 硬體與飛控 → 上場清單。

講課順序 先看電影 新手圖文 本隊定稿

一句話結論：攻擊用 火神 VCI 1507 或 DYH1408 ＋ 4S 高 C（OVONIC 960／1060、Tattu 球機 1100、Tattu V5 850）；防禦用 VCI 1408 ＋ 4S 高 C；輕量用 1404.5＋3S。

槳統一 2828-3。LED 22 顆（主 16＋尾 6）。飛控：Oxbot Flow AIO45／RATE F4／HAKRC F411。檢錄本場 5 球／9 電；1060 必實秤。

明天介紹 · 講課順序

依講師建議排程（約 70–90 分鐘）。選單已照此順序重排；時間不夠就砍括號內「可略」。

技術全解 · 雙軌別搞混

重點第 2–3 頁：FIDA Class 20 ≠ FAI F9A-B（重量、場地、射手人數）。本隊備賽走無刷 F9A-B。

規則檢錄 · 知道要過什麼

≤300 g、4S、槳 ≤76 mm、LED、1 名射手。有刷／Class 20 另開專頁對照即可，勿混講。

Attack

攻擊機

馬達 VCI 1507（或 DYH1408）· 槳 2828-3 · 電池 4S 高 C

飛控優先 Oxbot／RATE。Betaflight：small_angle=180、Failsafe DROP、ARM＝AUX1。

防守機

飛控可用 HAKRC F411；手感偏穩。LED 隊色與射手尾燈規則同攻擊機。
