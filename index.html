電池過放（學生最常毀電的原因）

過放＝電壓被拉太低還繼續飛。 損害通常不可逆——不是「充飽就好」。檢錄只有 9 顆電，一顆打穿就少一顆；硬撐會讓整隊電池陸續報廢。

現象對比賽／電池的影響

單芯到約 3.0 V 以下還在飛高風險鼓包、永久報廢；部分充電器拒絕充電

飛行中突然沒力、重開機、失控落地欠壓＋高電流；當場失分，也可能燒 ESC／接頭

為什麼足球機特別容易過放

  • 850mAh 很小：對抗局平均十數安培，理論續航本來就卡在 3 分鐘邊緣。
  • 1507／1408 電流大：猛頂瞬間壓降劇烈，燈號會比「靜止電壓」更早警告。
  • 看不見遙控電壓：只能靠 LED 紅閃——沒開警告＝不知道在過放。
  • 捨不得換電：9 顆電若不輪替，同一顆連打多 set 最容易打穿。

輕量機與 299g 滿載怎麼選？

策略優點缺點適合角色
較輕（約 250–285g） 加速、轉向與翻正較快；平均電流、溫升較低；續航較長；維修後較不易超重 碰撞時較容易被頂開；卡位與慣性較弱 防禦、控場、追球
偏重（約 285–295g） 碰撞與卡位較穩；高速衝撞動量較大；仍保留少量送檢容錯 轉向較鈍、耗電與溫升較高 攻擊、短時硬防
299g 貼上限 把合法質量幾乎用滿，硬碰硬時較不容易被推開 僅剩 1g 容錯；秤差、膠帶、換線或維修都可能超重；續航與靈活性最差 只適合實秤穩定且明確採硬撞戰術的攻擊機
為什麼學生機常接近 300g？ 20／22cm 球框、碳板、護罩、LED、線材和 80–100g 高 C 電池疊加後，本來就容易落在 290g 以上； 這通常是組裝結果，不代表 299g 一定是最佳性能。不要為了「用滿規則」額外加配重。
推重比：1507 單顆 651g → 四軸約 2.6kg；對 300g 球體推重比約 8–9:1。 動力過剩，瓶頸是散熱、電池 C 數與 300g 總重。
先做這一步：用電子秤實測「框架＋電池＋4馬達＋槳＋飛控」。 靠近 300g 就優先讓防禦減重（改 1404.5），攻擊可保留 1507 或 DYH。
