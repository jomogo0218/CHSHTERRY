LED

22 燈隊色與低壓紅閃。

隊色、射手尾燈、22 顆耗電、低壓紅閃與一路 LED 配線集中在這一頁。

燈在哪裡？誰可以進球？

環形主燈整場固定本隊紅／藍；尾巴燈用來分辨各機。只有 射手可以得分，射手尾燈必須是對方隊色（紅隊射手＝藍尾、藍隊射手＝紅尾）。

球機實務常用 5V 可定址燈條（WS2812B／SK6812），剪成主條 ≥16＋尾燈 ≥6。下方示意圖看裝在哪；整機外觀見組裝頁球機照。

顏色規定（FAI B.1.5）

名詞統一：射手 ＝ 攻擊手 ＝ 前鋒（striker）——同一個角色、同一台球機，不是三種人。本頁以下一律稱 射手。

規則重點：每隊只有 1 名射手，也是唯一可以得分的人；其餘隊員只能防守／導引。

燈位規定學生要做的
環形主燈≥16 顆；整場紅隊紅、藍隊藍賽前切成主辦指定隊色，任意角度都要看得清
尾巴識別燈≥6 顆；各機顏色彼此好分辨勿跟本隊紅／藍主色搞混
射手尾燈（＝攻擊手）紅隊射手＝藍；藍隊射手＝紅必須是對方隊色；換射手就要改這台尾燈

亮度與電量粗算（22 顆）

結論：續航幾乎都是馬達吃掉的；調 LED 亮度對飛多久影響通常 <3%（約 1–2 秒）。 調暗主因是不刺眼、BEC 較不熱。

① 單顆 WS2812

  • 全亮白光約 60 mA＠5V（約 0.3 W／顆）。
  • 純紅或純藍約白光的 1／3（約 20 mA＠5V）。

② 本隊：買 1m／60 燈條，只裝 22 顆

規格 1m／60 顆，裝機只留 主條 16＋尾燈 6＝22 顆。多的剪掉。
假設（22 顆）5V 端電流功率折回 4S 電池側
全亮白22×60mA＝1.32 A≈6.6 W≈ 0.52 A
純紅或純藍 100%22×20mA＝0.44 A≈2.2 W≈ 0.17 A
純色＋亮度 40%≈0.18 A≈0.9 W≈ 0.07 A
（對照）誤裝 60 顆純色 100%1.2 A≈6 W≈0.47 A；易壓垮飛控 5V

③ 3 分鐘耗電 ≈ 馬達能飛幾秒？

消耗 mAh ≈ 電流(A) × 0.05 × 1000；換算（馬達平均 15A）：秒數 ≈ mAh × 3.6 ÷ 15。

項目（22 顆） 電池側電流 3 分鐘耗電 佔 850mAh ≈ 馬達 15A 可飛
全亮白0.52 A≈26 mAh≈3.1%≈6 秒
純紅／藍 100%0.17 A≈9 mAh≈1.1%≈2 秒
純色 40% 亮度0.07 A≈3.5 mAh≈0.4%≈1 秒
100%→40% 省下的—≈5.5 mAh≈0.6%≈1–2 秒
馬達（對抗局平均）12–20 A≈600–1000 mAh整包整局 3 分鐘
平均 12A → 秒數 ×1.25；20A → ×0.75。調亮度一整局約差 1–2 秒。 仍建議 set ledstrip_brightness = 40：不刺眼、BEC 較涼。

低電壓必須紅閃提醒

選手常看不見遙控電壓表，靠球機燈號。低電要明顯閃爍，提醒減油、回邊、換電。

項目建議設定說明
警告 Warning單芯 3.5–3.6 Vvbat_warning_cell_voltage
最低 Minimum單芯 3.3 Vvbat_min_cell_voltage
LED 覆蓋燈珠加 W（Warnings）低電紅閃
視覺蜂鳴ledstrip_visual_beeper = ON蜂鳴時燈也閃
 
feature LED_STRIP
set ledstrip_brightness = 40
set ledstrip_visual_beeper = ON
set vbat_warning_cell_voltage = 35
set vbat_min_cell_voltage = 33
save

CLI 電壓單位 0.1V（35＝3.5V／芯）。燈珠例：led 0 0,0::CW:2。完整 3S／4S 電壓表見「電池」分頁。

注意：猛加油瞬間壓降可能短暫紅閃＝正常；一直紅閃＝真的沒電，減油或落地換電。

set 中射手（攻擊手）失能要換人

  • 隊長喊 timeout → 全隊落地 → 原射手離場 → 指定場上另一人當新射手（每 set 只能一次）。
  • 新射手尾燈必須改成射手規定色；主條隊色不用改。
  • 若主辦要求旗帶，改掛到新射手機。

技術現實：一般飛控只有一路 LED

環／尾若並聯或整條同色，就無法同時有隊色＋識別色。解法由易到難：

#解法做法適合誰
1專用射手機1 台固定射手尾燈色；換射手＝換人／換機全隊建議
2燈鏈分段環＋尾串成一條 WS2812；燈珠編號分色（0–15 隊色、16–21 尾燈）一路 LED
3AUX／撥桿切色預存一般／射手兩套，落地遙控切timeout 換射手
4尾燈硬體開關飛控只驅環燈；尾燈獨立撥色不會分段時
5雙路輸出少數板有 LED2 或外掛控制器一般飛控沒有
小隊建議：檢錄 5 機至少 1 台射手機＋其餘分段燈色；有餘力再加 AUX 切色。 Betaflight LED Strip
