新手入門（圖文詳解）

完全沒碰過無人機也可以從這裡讀。每個零件都用「它是什麼 → 為什麼重要 → 本隊怎麼選」說明，並配上真實器材圖。

先建立三個觀念（請慢慢讀完）

1. 足球無人機不是玩具遙控車那種「開了就會」。 它是一台真正會飛的四軸飛行器，外面套一顆球形防護罩（像籠子），所以撞牆、撞對手通常不會直接把槳打到人。比賽時大家在網籠場地裡，用遙控器控制自己的球機去「頂開對手、帶球、穿過圓形球門」。

2. 本隊正式備賽走「無刷 FAI F9A-B」。 你會看到網站也有「有刷／空心杯」頁面——那是另一種較輕、較入門的機種與賽制（FIDA Class 20）。兩邊都叫 20 cm 球，但重量差很多（約 110 g vs 300 g），規則也不一樣。新手若搞混，會買錯零件、秤錯重量。

3. 這份手冊的閱讀順序建議： 先看 影片 有畫面 → 讀完本頁認識零件 → 再看 規則檢錄 知道要過什麼門檻 → 最後才進馬達／電池／組裝細節頁背數字。

什麼是「球機」？

用生活比喻理解

想像一顆籃球大小的圓籠，裡面掛著一台小四軸無人機。馬達轉槳產生升力，整顆球就能起飛、前進、轉彎。因為有外殼，兩機對撞時多半是「殼撞殼」，比一般穿越機（槳外露）安全很多，也更適合在教室／體育館做團隊運動。

比賽時每個人遙控自己的一顆球。其中有一個特別角色叫「射手」（英文 striker，有人叫前鋒／攻擊手）——只有射手進對方球門才算得分。其他人的工作是保護、擋人、帶球給射手，或守住己方球門。這跟一般足球「誰踢進都算」不一樣，所以燈光顏色很重要：裁判與對手要一眼看出誰是射手。

一台無刷球機大概有哪些零件？

本隊無刷機（FAI F9A-B）送檢時，秤上的重量幾乎包含下面全部東西加總（含電池）：

  • 球形外框（球殼）：塑膠或複合材料做成的籠子，保護內部，也決定能不能通過直徑檢查。
  • 碳纖維中心板／機架：固定馬達與飛控的底板，要夠硬才不會撞一撞就歪。
  • 四顆無刷馬達＋四支槳：產生推力；正槳與反槳要對角安裝，否則機會自己轉圈。
  • 飛控（常做成 AIO＝飛控＋電調一體板）：像大腦＋四肢驅動，聽遙控器指令、穩定姿態。
  • 鋰聚合物電池（LiPo）：電力來源；本隊比賽常用 4S（四芯串聯）。
  • LED 燈條：顯示隊色與射手身份；規則有最少顆數。
  • 接收機／天線：收遙控訊號（本隊常用 ELRS 這類協議）。
  • 線材、插頭、魔鬼氈、螺絲：看起來不起眼，但都會進秤，也最容易在維修時「偷偷變重」。

規則上限是 含電池總重 ≤300 g。所以組裝時不是「零件愈強愈好」，而是「夠用又過得了秤」。

馬達：為什麼攻擊機與防守機不一樣？

無刷馬達在做什麼？

馬達轉動螺旋槳，把電力變成「往下推空氣」的力，機體就往上飛。推力愈大，加速、爬升、頂人時愈有力；但通常也愈吃電、愈重、愈熱。

攻擊機常需要突然衝刺、卡位、擠開守門員，所以本隊優先選推力高的 VCI 1507（或 DYH1408）。你可以在 馬達頁 看到測功曲線：油門拉到中高段時，1507 的推力明顯較高。

防守機要飛得久、轉得靈、比較不那麼「暴衝」，本隊常用較均衡的 VCI 1408。若還要更輕，才會考慮更小的 1404.5 搭配 3S 電池——但那是進階取捨，新手先記「攻擊 1507、防守 1408」即可。

新手最常踩的坑：孔距

馬達要用螺絲鎖在碳板上。不同馬達的螺絲孔圓心距離不一樣（例如 Φ12 與 Φ9）。孔對不上就不能硬鎖，否則會歪、會裂板、飛起來振動大到像壞掉。

所以換馬達前先問老師／學長：我們這塊板是哪一種孔？再對照馬達頁的規格圖。詳細數字與排序請進 馬達。

電池：不是「毫安愈大愈好」這麼簡單

你需要聽懂的三個詞

  • 4S：四顆電芯串聯，標稱約 14.8 V。FAI F9A-B 最高只能 4S；拿 6S 去比賽是直接違規。
  • mAh（毫安時）：容量大概，數字大通常飛久一點，但也較重。太重會讓整機逼近 300 g。
  • C 數：粗略代表「能不能瞬間放電」。足球機常猛催油門，需要「高 C」才不容易電壓掉下來、飛控重開或動力變軟。本隊口訣是 4S 高 C。

檢錄時還會量「每一芯有沒有超過 4.25 V」。有些電池能充到更高（LiHV），但比賽不能充那麼滿上場。細節與候選清單見 電池、電池圖鑑。

螺旋槳：為什麼要統一 2828-3？

槳決定「咬多少空氣」

同樣的馬達，換不同槳，推力與電流會差很多。規則規定槳徑最大約 76 mm（3 吋），而且禁止金屬槳（安全與規則雙重原因）。

本隊統一 2828-3（三葉），是為了：測功數據能互相比較、備品好共用、維修時不會裝錯尺寸。槳還有「正轉／反轉」——裝反會飛不起來或狂轉，組裝時一定要對照說明書與學長示範。

完整合規表與 HQProp 產品照見 螺旋槳。

飛控／AIO：球機的「大腦＋四肢」

它負責什麼？

飛控讀陀螺儀（感應機身姿態），再命令電調去驅動四顆馬達，讓球機聽你搖桿的意思，而不是自己亂翻。現在很多板子把「飛控＋四合一電調」做在同一片，叫 AIO，省空間也省焊點。

本隊常見選項包括 Oxbot、RATE F4、HAKRC F411 等。你現在不需要一次背完所有接腳，但要知道：

  • 接錯電源極性會燒掉板子；
  • 必須設定 Failsafe＝失控立刻停轉（安全鐵律）；
  • 設定可用 Betaflight 模擬頁 先練習，再上真機。

接線圖與產品說明見 飛控硬體、飛控設定。

為什麼要有「接口圖」？

板上每一排針腳都有固定用途：接收機訊號、LED、蜂鳴器、USB 設定口等。新手最怕「看起來長得很像就亂插」。正確做法是：把手機或筆電打開這張圖，一根一根對，對完請學長檢查，再通電。

LED：不是裝飾，是比賽身分證

為什麼燈那麼重要？

球場上同時可能有很多顆球在飛，裁判與對手要在 0.5 秒內判斷「這是紅隊還是藍隊」「哪一顆才是可以得分的射手」。所以規則要求：

  • 主燈（環形）至少 16 顆，整隊統一紅或藍；
  • 尾燈至少 6 顆，用來分辨個別球機；
  • 射手的尾燈必須是「對方隊色」（紅隊射手用藍尾、藍隊射手用紅尾），才夠醒目。

本隊實務做成約 22 顆（主 16＋尾 6）。亮度不用開到刺眼，但要保證場邊看得見。換射手時，記得改尾燈顏色——中場通常來不及接電腦，所以要事先準備好切換方式。完整說明見 LED。

若你先摸到的是「有刷／空心杯」機？

跟本隊無刷備賽有何不同？

有刷空心杯機通常更輕、更便宜、開箱即可飛，適合先練方向感與團隊配合。它常見於 FIDA Class 20（總重約 ≤110 g）。遙控器上常有「定高」「大小動」開關，新手可以先開定高把高度穩住，再慢慢練前進與轉向。

但請記住：有刷機的規則、場地、射手人數，與 FAI F9A-B 無刷備賽不是同一套。正式要打本隊那種無刷賽，仍要回到 300 g、4S、自組飛控那條路。完整對照與 Class 20 規則見 有刷／空心杯。

第一次上手遙控器怎麼做？

  • 先問清楚電源順序（常見：先開遙控，再給機身通電）。
  • 油門（通常左搖桿上下）慢慢推，不要一秒推到底。
  • 定高打開後，先練習左右與前後，再練習轉彎。
  • 落地後先把油門收到最低，再依規定斷電。

讀完本頁，接下來做什麼？

  1. 打開 規則檢錄，把「300 g、4S、槳 76 mm、LED、1 名射手」用自己的話講給同學聽一遍。
  2. 到首頁看 本隊定稿：攻擊與防守各記一組配備。
  3. 再進 馬達／電池 看圖與表格（此時再看數字才有意義）。
  4. 組機前讀 組裝；上場前用 上場清單 逐項勾選。

有任何名詞看不懂，先回到本頁搜尋標題，或問學長「這個零件在球機的哪裡」。不要害羞——足球無人機本來就該從零講清楚。
