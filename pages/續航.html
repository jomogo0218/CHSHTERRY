馬達＋電池能飛多久。

馬達＋電池能飛多久：控場／對抗／猛攻粗估。一 set 約 3 分鐘，結束就換電。

這頁怎麼讀？

左邊想成你掛哪顆馬達（攻擊 1507 最吃電），右邊想成電池容量與 C 數。表格不是保證飛滿 3 分，是排電池與換電節奏用。

對照實體：攻擊常搭配高 C 850／960；防守可較省電的 1408 系。細節見 馬達、電池。

攻擊：1507
防守：1408
常用：850 高 C
偏小：650

馬達＋電池能飛多久？

怎麼估：可用電量 ≈ 標稱容量 × 80%（不要飛到過放）。時間（分）≈ 可用 mAh ÷ 整機平均電流(A) ÷ 1000 × 60。

下表電流是四顆馬達合計的粗估值（不是滿油門），實戰會隨對抗強度變動；數字僅供排電池，不是保證值。

三種飛法的平均電流（粗估）：
  • 火神 VCI 1507：控場約 14–17A；對抗約 22–26A；猛攻約 32–40A
  • DYH1408／火神 VCI 1408：控場約 12–15A；對抗約 18–22A；猛攻約 28–35A
  • 火神 VCI 1404.5（3S）：控場約 10–13A；對抗約 15–18A；猛攻約 22–28A

可用電量＝容量×80%。時間四捨五入到 0.1 分。1507 請配 ≥120–150C；650／750 的 95C 對 1507 供電偏緊，即使「算得出時間」也容易壓降落地。
怎麼記：
  • 1507：掛 850 猛攻通常飛不滿 3 分；960／1060／1100 比較寬，但仍要控油門。
  • 1408／DYH：850 控場可過 3 分；要對抗較穩就用 960 以上。
  • 1404.5＋3S 1100：最容易飛滿 3 分，但射門／硬頂較弱。
  • 比賽流程：一 set 約 3 分鐘，結束就換電。表上「夠不夠」是指局內會不會提早紅閃，不是說一顆電連打多局。
比賽實務：射手（攻擊手）建議每 set 換一顆熱電（備 4–6 顆同規格），不要指望單顆猛攻撐完整場。
