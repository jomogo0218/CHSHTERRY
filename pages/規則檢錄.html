規則檢錄（FAI／FIDA 分開說明）

兩個國際組織各有一套足球無人機規則。本頁先對照差異，再分章說明；本隊無刷備賽以 FAI F9A-B 為主。

給完全新手：為什麼要分兩個協會？

FAI（國際航空運動總會）把無人機足球編成正式航空運動項目，代號 F9A。本隊組無刷機、刷 Betaflight、衝 ≤300 g，走的是這條線的 F9A-B（約 20 cm 球）。台灣對接 FAI 的窗口常聽到 CTAF（飛行運動總會）與國家證照體系。

FIDA（國際無人機足球總會）推動休閒／教育／職業聯賽實務，機種常稱 Class 20／Class 40（約 20 cm／40 cm）。校園常見的有刷空心杯 RTF、定高遙控，多半對應 Class 20（≤110 g）。台灣推廣端也會聽到 CDSA 等對接 FIDA 的單位。

最重要的一句：兩邊都有「20 cm 球」，但重量、場地、球門、射手人數、能不能改裝都不一樣。聽老師說「去打 20 cm」時，一定要再問清楚是 FAI 還是 FIDA。

① FAI 規定（本隊無刷備賽）

依據 FAI Sporting Code Section 4, Volume F9 Drone Sport（2026 版）。爭議以英文原文與主辦公告為準。

F9A-B 場地與球門（建議尺寸）

  • 飛行區／防護籠：長邊約 6 m、短邊約 3 m、高約 3 m（長邊須為短邊兩倍之原則）。
  • 球門環：內徑建議 40 cm、外徑建議 70 cm、厚度上限約 10 cm；置於底線內側約 1 m。
  • 場上人數：3 至 5 名（主辦在賽事公告訂定）；每隊僅 1 名射手可得分。

F9A-B 機體關鍵限制（檢錄會查）

下面每一條都用「規則在說什麼 → 你要做什麼」寫給新手：

  • 總重 ≤300 g：含球框、電池、馬達、槳、飛控、LED、線材、膠帶——秤上全部都算。實務目標 285–295 g，不要衝 299 g。
  • 馬達：只能用電動馬達，最多 4 顆（四軸）。
  • 電池：最高 4S；每一芯滿電 ≤4.25 V（4S 整包 ≤17 V）。可於每一 set 前量測。6S 違規。LiHV 即使能充更高，上場也不可超標。
  • 螺旋槳：最大約 3 吋／76 mm；禁止金屬槳。用卡尺量「尖到對尖」。
  • 框架：塑膠或複合材料，禁止金屬骨架；零件不可突出球框外；底部平面 ≤2 cm；單一開口 ≤150 cm²。
  • LED：主條 ≥16（可切紅／藍隊色）；後方識別燈 ≥6；射手尾燈必須是對方隊色。細節見 LED。
  • 安全：須有 fail-safe，觸發後馬達立刻停止；允許烏龜／翻正；禁止預編程機動、自動定位或路徑修正。
  • 射手：每隊場上僅 1 人可得分，須以尾燈或主辦標示帶明顯區分。
名詞：射手 ＝ 攻擊手 ＝ 前鋒（FAI 英文 striker）。本站一律稱「射手」。

FAI／本場檢錄實務（Processing）

賽前送檢、賽中可抽查；合格後貼標示。未通過規格＝不能上場。

本場賽事規定（以主辦公告為準）：每組檢錄上限「球機 5 顆、電池 9 顆」。 送檢時就要決定帶哪 5 機、哪 9 電；未檢錄的機／電不得上場。 （FAI 世界賽級 F9A-B 常見每隊可備較多機，僅供對照。）

建議分配：攻擊 1–2＋硬防 1–2＋輕防／備機 1；電池 9 顆支應約 3 個 set 的換電。電池編號並記錄滿電電壓（≤4.25 V／芯）。

時程概念：賽前正式檢錄並標示 → 起飛前可再檢查 → 每 set 前可量電壓 → 賽中可抽查。備機未上場不裝電池；換機／換電多半只在 set 間。地方賽程序可簡化，但規格數字仍要過。

② FIDA 規定（Class 20／40）

依據 FIDA Dronesoccer Rule Book（Class 20 以 2025-10-01 修訂為準）。完整攻防、越位、點球罰則見 有刷／空心杯專頁；此處先把「規格與差異」講清楚。

Class 20（約 20 cm／入門與教育常見）

Class 20 的設計目標是：較小場地、較輕球機、較容易在教室或活動中心架起來打。實務上很多隊伍使用有刷空心杯 RTF（開箱即飛），但規則書驗的是重量與外形等規格，並禁止為提升性能而改裝。

項目Class 20 規定和 FAI F9A-B 差在哪？
球徑20 cm ±1 cmFAI 用「+2 cm／Ø22 cm 圈」量法
重量≤110 gFAI 是 ≤300 g（幾乎三倍）
場地8 m × 4 m × 高 3 mFAI 建議 6×3×3 m（較小）
球門內徑30 cm ±1 cmFAI 建議 40 cm
單面開口≤70 cm²FAI ≤150 cm²
射手最多 2 名可得分FAI 僅 1 名
改裝禁止性能向改裝FAI 允許自組但須合規
同場機種同場不得混用不同型號球機FAI 以規格合規為主
賽制時間常為 3 set × 3 分鐘（主辦可改）依 FAI／主辦公告
  • 球門位置／高度：自短邊中心向中線約 1.5 m；球門中心離地約 1.8–2.2 m。
  • LED／射手標：須能紅藍辨隊；射手標示脫落導致無法辨識時，之後進球可不計。
  • 攻防重點（摘要）：射手完整穿過對方球門正面才得分；穿過對方球門會進越位，需全隊回己方半場解除；防守不可逆向進出己門。詳見 有刷頁完整規則。

Class 40 與 F9A-A 都是「大球場」，但場地尺寸、電池上限、射手規則仍可能不同。打大型賽前請下載當屆 FIDA／FAI 原文，不要只背這張摘要表。

FIDA 檢錄／上場心態（新手）

  • 先確認主辦指定的官方或認證球機型號；Class 20 通常不能私自改槳、改電壓來變快。
  • 用比賽狀態秤重，確認 ≤110 g（Class 20）。
  • 隊色 LED、射手標示賽前通電檢查；備電分開存放。
  • 若你之後要轉打本隊無刷 FAI，請回到上方「① FAI」與 組裝，重新用 300 g 思維組機。
