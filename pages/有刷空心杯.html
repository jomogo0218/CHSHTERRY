有刷／空心杯專頁

對照本站無刷 F9A-B：空心杯原理、FIDA Class 20 完整規則、裝備與檢錄。

一句話定位：有刷（空心杯）球機是教育入門／FIDA Class 20主流；本站其餘頁面以無刷 FAI F9A-B（≤300 g）備賽為主。兩者場地、重量、能否改裝皆不同，勿混用規格。

官方與採購參考： FIDA 國際總會 · Skyball（韓原廠／Helsel） · 宇宙機器人（台灣教具通路）

空心杯馬達資料

什麼是空心杯（Coreless）

有刷馬達的一種：轉子是輕薄杯形線圈、沒有鐵芯，慣量小、起動快、體積輕，適合 ≤110 g 球機。

  • 電流經碳刷／換向器換向 → 故稱「有刷」。
  • 轉速隨電壓與負載變；無電子換相，不需無刷 ESC 那套時序。
  • 常見於玩具機、入門球機、STEM 教具。

對上無刷（本站馬達頁）

無刷用三相電＋ESC 電子換相，效率高、壽命長、推力大，是 F9A-B 攻擊／防守主力。

  • 詳見 馬達：VCI 1507、DYH1408、1408…
  • 有刷勝在：便宜、好換、上手快、碰撞後維修門檻低。
  • 有刷弱在：碳刷磨耗、滿載發熱、推力／效率不如同尺無刷。

耗損與維修重點

  • 碳刷／軸承磨耗：推力變弱、異音、單側無力 → 整顆馬達更換最快。
  • 槳葉：對撞後先檢查是否缺角、是否裝反（CW／CCW）。
  • 配線：空心杯線細，反覆折彎易斷；維修時預留應力緩解。
  • Class 20 禁改裝：不可私下換更大槳、加電壓、改增益來「變快」；正式賽用官方認證球機。
  • 練習場：可在非官方練習用同款備品；正式賽仍以主辦指定機種為準（同場不得混用不同型號球機）。

球門（Class 20）

  • 圓形：內徑 30 cm ±1 cm，外徑 50 cm ±1 cm，厚度 10 cm。
  • 兩側球門尺寸／重量須一致。
  • 位置：自短邊中心向中線方向 1.5 m。
  • 高度：球門中心離地 1.8–2.2 m；可吊掛或立柱支撐，須正對場地中心、不可左右晃。
  • 須有紅／白 LED（內或外裝），可由場外手動操作；廣告不得妨礙辨識燈號。

完整比賽規則（Class 20）

以下依 FIDA Class 20 規則書整理，供課堂與社團對照；正式裁決以主辦與裁判為準。

1. 人數與角色

  • 報名名單上限 10 人／隊（含教練 ≤3）。
  • 上場：每隊 5 人、5 球；一人一機。
  • 最少 3 人即可開打（含射手人數不足時之處理見下）。
  • 每隊最多 2 名射手（Striker）可得分；其餘為防守／導引。
  • 開賽前未滿 3 人就位 → 視同棄權；第 2／3 set 未滿 3 人 → 該 set 判負並進入維修時間。
  • 換人僅限 set 開始前；名單內不限次數；教練不得上場當選手。
  • 換人須告知裁判，且在球機進入 Skyfence 前完成；可換或不換球機。

2. 賽制時間

  • 一場 3 個 set，每 set 3 分鐘（主辦可預先公告調整）。
  • 猜拳勝方選飛行員區（左／右）；原則三 set 固定；裁判認定不公可改。
  • 開賽前至少 10 秒「準備」訊號，再給「開始」；set 中不可暫停（timeout）。
  • set 結束後維修／戰術時間原則 ≥5 分鐘（自全員收球離場起算）；裁判可延長，但不可只因某隊未就緒而延長。
  • 因 ≥3 人維修延誤而輸掉該 set 時，裁判可於標準維修外再給 3 分鐘。
  • 準備訊號前 10 秒至 set 結束，除主審外任何人不得干擾比賽。

3. 得分

  • 射手球機由球門正面完整穿過到背面 → 算進球。
  • 不算：越位狀態進球；未完全穿過即彈回；由球門背面往正面穿過（且視為越位）。

4. 越位（Offside）

  • 射手以任何方向穿過對方球門 → 全隊進入越位，不可再得分。
  • 解除：該隊當時在對方半場的所有球機，都回到己方半場（過中線）。
  • 若有球失控卡在對方半場：須宣告放棄該 set 並放下遙控器，越位才解除；若失控的是射手，依規則替補之新射手亦須回到己方半場。

5. 防守

  • 可自球門正面進入防守；禁止逆向進出（由背面進入，或超過一半進入後再退出等，規則書圖示）。
  • 逆向進入屬犯規，可判十二碼（見罰則）。

6. 十二碼／點球（Penalty Kick）

出現下列情形可判給對方點球：

  • 無視越位連續得分；
  • 自方球門逆向進入；
  • 單場累計警告 ≥2 次（警告跨 set 累計，下场比賽歸零）。
  • 時機：每個 set 結束後執行。
  • 形式：射手 vs 守門員 1 對 1；每次 5 秒；射手自中線起飛，守門員自開賽防守位。
  • 時限內可多進球，越位規則同樣適用。
  • 雙方罰則可互抵後只執行淨差額；主辦亦可改為直接加分而不實際罰踢。
  • 分組賽為計算淨勝球，原則仍須執行（除非主辦改加分制）；淘汰賽獲點球方可放棄執行。

7. 勝負

  • 單 set 進球多者勝；平手則該 set 平手。
  • 先勝 2 個 set 者勝整場。
  • 三 set 後仍未有一方勝兩 set：可打延長 set；再平則互射（各 3 人，仿點球；仍平則一人一人加賽至分出勝負）。
  • 若賽制允許平手，可不延長、不互射。

8. 選手裝備（允許／禁止）

類別內容
基本服裝或隊服（便服須有可辨識配件，如帽子／背心／大於 A4 標誌）；合規球機；綁定遙控器；備電
可選FPV；備機（電池須拆開分開放）；電壓表與緊急維修工具
禁止干擾對手的燈光；干擾對手的無線電；干擾比賽的音訊；任何為提升性能的改裝（Class 20 明文）

雙方賽前應互查裝備；有疑義須事先揭露。禁止裝備若賽前棄用可照常比賽；若雙方事前同意可免罰；賽中被認定影響比賽 → 該 set 判負。

9. 球機識別與顏色

  • 須能亮紅／藍 LED 區分隊伍。
  • 射手須有額外標示（依賽事規定）；標示脫落導致對方難以辨識 → 脫落後進球無效。
  • 可塗裝，但不可用會混淆隊色的紅／藍；同隊上場球機不得塗不同色。
  • 廣告：官方賽球機原則僅允許賽會徽章、組委會標誌、製造商標；細節依當屆章程。

10. 警告／set 負／整場負

等級典型情形
警告非選手滯留飛行員區；輕微不文明；擅自移動場地設備圖利；開始訊號前移動球機；不服從合法指令
累計 2 警告對方獲 1 次點球機會
該 set 判負嚴重不文明；故意改隊色；用手／腳／器具移動球機圖利；重複同警告意圖拖延或抗議
整場判負故意用球機威脅他人安全；嚴重不文明；非報名選手非法上場

11. 裁判要點（摘要）

  • 每場 1 名主審 + 助理裁判（可增至 4：進球審、犯規審等）。
  • 主審對進球、比賽進行與結果有最終裁決權；VAR 若啟用依 Class 40 VAR 規則。
  • 訊號：準備／開始／結束有標準手勢與哨音；助理用旗或 LED 示意進球／越位／犯規。

改裝禁止性能向改裝外觀貼紙勿蓋住 LED／射手標
LED／射手標紅藍可辨；射手標牢固賽前通電檢查；備標示帶
遙控綁定一人一機、訊號不干擾他機多機同時開機預飛測
電池備電足夠；備機電池分離編號；每 set 間換電
禁帶物品干擾燈、干擾無線電、干擾音訊飛行員區只留必要裝備
人員名單內選手；教練不上場set 前完成換人登記

上場前 5 分鐘（有刷版）

  1. 確認隊色 LED、射手標。
  2. 槳向正確、無裂；螺絲鎖固。
  3. 定高／大小動位置講好戰術（開場小動、衝門切大動）。
  4. 起飛點放齊；飛行員就位；聽準備哨。
  5. set 間：換電、清槳屑、檢查空心杯是否單側無力。
